## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Destructive git with uncommitted work | A `git reset --hard HEAD~1` used only to drop a throwaway probe commit wiped 612 files of finished, gate-passing work (2026-09-18). An earlier `git checkout --` on four files silently reverted part of the same change set. | advisory | Commit the moment gates pass. `git reset --soft` to drop a commit. Never exercise git behavior in the live tree — use `mktemp -d` + `git init`. |
| A zero result treated as evidence | `git grep -c -- "<pat>"` makes git parse the pattern as a pathspec and silently return zero. It reported clean on a dirty repo and masked the data loss above for several steps. | advisory | Use `-e`. Prove any "0 found" by first showing the same command returns a hit on a planted known-positive, then delete the probe. |

| Absolute home paths in generated artifacts | Passing absolute paths into a planner prompt put them in the plan's `<automated>` blocks, tripping `verify_no_home_paths.sh`. | advisory | Pass repo-relative paths to subagents. The commands work identically. |

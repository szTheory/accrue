| Boundary | Description |
|----------|-------------|
| admin or host input -> `Accrue.Billing.refund/2` | Untrusted refund amount and reason enter the billing context |
| `RefundActions` -> Braintree adapter | Local commands become external processor mutations |
| migration SQL -> existing refund rows | Brownfield identity backfill modifies persisted financial records |

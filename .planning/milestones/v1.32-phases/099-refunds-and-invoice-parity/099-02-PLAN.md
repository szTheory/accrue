| webhook payload -> reducer | Untrusted external event data attempts to mutate local financial state |
| reducer -> canonical refund fetch | Webhook trigger causes external state rehydration from Braintree |
| subscription mutation opts -> Braintree plan update | Caller-supplied proration knobs become provider billing behavior |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-99-06 | D | `accrue/lib/accrue/webhook/default_handler.ex` | mitigate | Reuse the existing orphan telemetry and clean deferral path so out-of-order Braintree child events do not crash the reducer loop. |

| T-99-08 | I | `accrue/lib/accrue/billing/invoice_projection.ex` | mitigate | Keep invoice sale totals unchanged and expose only derived refund rollups, preventing misleading "netted" financial truth in operator reads. |

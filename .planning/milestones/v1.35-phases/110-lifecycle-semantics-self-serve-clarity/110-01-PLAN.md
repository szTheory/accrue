| Boundary | Description |
|----------|-------------|
| canonical lifecycle meaning -> provider-specific guides | If provider guides redefine lifecycle semantics, adopters and maintainers get contradictory mental models for the same facade. |
| action semantics -> docs | If docs imply parity or instant finality that runtime actions do not guarantee, users may take destructive actions under false assumptions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-110-01 | T | `accrue/guides/*.md` lifecycle docs | mitigate | Centralize lifecycle meaning in one SSOT and require provider-specific docs to link back to it instead of drifting. |
| T-110-02 | R | self-serve cancellation wording | mitigate | Make end-of-period cancellation the default documented posture and reserve immediate cancellation for explicit exceptional flows. |
</threat_model>

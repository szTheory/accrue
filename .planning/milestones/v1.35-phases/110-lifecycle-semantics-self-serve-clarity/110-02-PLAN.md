<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| predicate semantics -> rendered UI | If rendered labels ignore predicate truth, customers and operators can misread scheduled-end or paused subscriptions as simply active. |
| action semantics -> helper text | If helper text promises unsupported provider behavior, users may expect reversible actions that runtime intentionally rejects. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-110-03 | T | portal/admin/example-host lifecycle surfaces | mitigate | Derive lifecycle labels from predicates and align helper text to typed action semantics. |
| T-110-04 | E | self-serve cancellation wording | mitigate | Make the default action clearly about renewal timing and access end, reserving immediate cancel for explicit exceptional operator flows. |
</threat_model>

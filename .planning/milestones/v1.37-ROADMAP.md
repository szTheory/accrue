# Milestone v1.37: Subscription Change Management

**Status:** ✅ SHIPPED 2026-05-07
**Phases:** 117-119
**Total Plans:** 9

## Overview

Closed the most visible post-checkout SaaS billing depth gap by promoting
active subscription changes into one first-party contract across the public
billing facade, admin/operator tooling, customer self-serve portal, package
docs, host mirrors, and the support-contract verifier bundle, while keeping
Braintree explicitly bounded to resolver-backed plan swaps.

## Milestone Summary

**Decimal Phases:**

- None

**Key Decisions:**

- Decision: Treat `swap_plan/3` and `preview_upcoming_invoice/2` as the official active-subscription-change facade instead of implied helper behavior.
- Decision: Promote quantity and subscription-item mutations as first-party only for Stripe and Fake; Braintree stays explicitly swap-only.
- Decision: Keep `.planning/processor-support-matrix.md` plus lifecycle/package docs as the canonical contract spine, with host docs and verifier scripts acting as thin mirrors.
- Decision: Require `:plan_resolver` as the only supported bridge for Braintree plan swaps from app-facing plan IDs to provider mutation metadata.

**Issues Resolved:**

- Closed the active-subscription-change gap across public facade APIs, support labels, docs, admin UI, and portal UI.
- Added preview-before-commit guidance and proof without implying unsupported cross-provider parity.
- Made Stripe/Fake quantity and subscription-item changes part of the explicit first-party contract.
- Locked the bounded Braintree swap-only story across runtime, docs, host mirrors, and verifier scripts.

**Issues Deferred:**

- Broader pause/resume and lifecycle recovery semantics remain outside this milestone.
- Subscription schedule management and broader preview/proration parity remain future work.
- Hyperwallet reopening and `FIN-03` finance exports remain explicit non-goals.
- Linked Hex release-readiness and publish operations remain post-archive follow-up work.

**Technical Debt Incurred:**

- No dedicated `v1.37` milestone audit artifact was run before archival; closeout proceeded on targeted phase verification plus a clean open-artifact audit.

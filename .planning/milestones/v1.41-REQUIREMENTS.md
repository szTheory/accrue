# Requirements: Accrue — Milestone v1.41

**Defined:** 2026-05-26
**Core value:** A Phoenix developer can install Accrue + its companion admin UI, and launch a real SaaS with subscription billing on day one — complete, production-grade, idiomatic Elixir DX, strong domain modeling, tamper-evident audit ledger, great observability, and zero breaking-change pain through v1.x.

## v1.41 — Admin global search (native Postgres)

**Goal:** Provide an Ecto-native global search for Customers, Invoices, and Subscriptions within the `accrue_admin` UI using native PostgreSQL full-text search (`pg_trgm`). This approaches the Stripe Dashboard UX for operators without introducing any separate sidecar dependencies like Meilisearch or Scrypath, maintaining the project's zero-sidecar philosophy.

**Source:** Intake-gated maintenance mode. The 2026-05-26 milestone next-step assessment selected Admin global search as the highest-leverage operator win remaining. Seeded from SEED-002 #5 but explicitly bounded to `pg_trgm` to preserve the zero-sidecar philosophy.

## v1 Requirements

Requirements for this milestone. Each maps to exactly one roadmap phase.

### Foundation & Postgres Native Search

- [ ] **SRCH-01**: An Ecto migration adds the `pg_trgm` PostgreSQL extension (if not already present) and necessary GIN indices on the `accrue_customers` (email, name), `accrue_subscriptions` (processor_id), and `accrue_invoices` (processor_id, number) tables for fast trigram similarity search.
- [ ] **SRCH-02**: The `Accrue.Billing` context exposes a unified `search/1` (or scoped `search_customers/1`, etc.) API backed by `pg_trgm` similarity queries, returning bounded and ranked results.

### Operator UI & UX

- [ ] **SRCH-03**: A global search bar is present in the `accrue_admin` UI layout that allows operators to type and instantly see a unified dropdown of matching Customers, Invoices, and Subscriptions.
- [ ] **SRCH-04**: The search UI supports keyboard-first navigation: `CMD+K` (or `Ctrl+K`) to open the search modal, arrow keys to navigate results, and `Enter` to jump to the selected record's detail page.

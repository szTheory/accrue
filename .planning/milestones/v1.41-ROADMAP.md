# Roadmap: Accrue

## Active Milestone

🚧 **v1.41 — Admin global search (native Postgres)** (Planning) — Phases **133–134**.

**Milestone goal:** Ecto-native global search for Customers, Invoices, and Subscriptions in the admin UI using Postgres native text search (`pg_trgm`), approaching the Stripe Dashboard UX without adding a separate sidecar dependency.

**Phase numbering:** continues from v1.40 (ended at Phase 132) → starts at **Phase 133**. Not reset (DEFAULT mode).

## Overview

Admin search is the highest leverage operator win remaining. The build relies entirely on Postgres native extensions (`pg_trgm`) to preserve the library's zero-sidecar philosophy. The milestone is split into two phases: foundation (database migrations for extensions/indices and Ecto queries) and UI (global search modal in `accrue_admin` with keyboard-first CMD+K navigation).

## Phases

- [ ] **Phase 133: Native Postgres Search Foundation** - Ecto migration to enable `pg_trgm` and add GIN indices, plus unified `Accrue.Billing` search functions.
- [ ] **Phase 134: Admin Global Search UI & Keyboard Nav** - LiveView modal in `accrue_admin` supporting CMD+K, type-to-search, and keyboard result navigation.

## Phase Details

### Phase 133: Native Postgres Search Foundation

**Goal**: The database is equipped for fast text search and the billing context exposes a unified API to query across core domain objects.
**Depends on**: Nothing
**Requirements**: SRCH-01, SRCH-02
**Success Criteria** (what must be TRUE):

  1. A new Ecto migration safely enables the `pg_trgm` extension (if not exists) and adds appropriate GIN indices for trigram search on `accrue_customers`, `accrue_subscriptions`, and `accrue_invoices`.
  2. `Accrue.Billing` exposes search functionality capable of fuzzy-matching customer names/emails, and exact-matching processor IDs and invoice numbers.

**Plans**: To be determined during phase planning.

### Phase 134: Admin Global Search UI & Keyboard Nav

**Goal**: Operators can instantly search across billing records using a keyboard-first global search modal in `accrue_admin`.
**Depends on**: Phase 133
**Requirements**: SRCH-03, SRCH-04
**Success Criteria** (what must be TRUE):

  1. A global search bar or button is present in the main `accrue_admin` layout.
  2. Typing `CMD+K` (or `Ctrl+K`) opens the search modal and focuses the input.
  3. The modal displays a unified list of matching records with visual distinction between types (Customer, Subscription, Invoice).
  4. The operator can use the up/down arrow keys to select results and `Enter` to navigate to the selected record.

# Requirements: Accrue

## Milestone: v1.42 — Ad-hoc Invoices & Adopter Confidence

Current focus: **Polish & Adopter Confidence**.

### Billing & Domain (BIL)

- [x] **BIL-08** — Public API for adding/removing ad-hoc line items to a draft invoice.
  - Host can add one-off charges or credits (negative amount) to an existing draft invoice.
  - Host can remove an ad-hoc line item before finalization.
  - Supported across Fake and Stripe.
  - Telemetry + Ledger events for manual adjustments.

### Admin UI (ADM)

- [ ] **ADM-17** — Admin UI support for managing ad-hoc line items.
  - Admin can view ad-hoc line items on an invoice detail page (Draft status).
  - Admin can add a manual line item (description, amount, currency) via the UI.
  - Admin can remove a manual line item.
  - UX aligned with `ax-*` and token discipline.

### Adopter Confidence (PROOF)

- [x] **PROOF-04** — Metered usage demonstrated in `examples/accrue_host`.
  - Host app includes a "Metered Feature" example (e.g. "API Calls" or "SMS Sent").
  - Host demonstrates calling `Accrue.report_usage/3` from a business process.
- [x] **PROOF-05** — Checkout facade demonstrated in `examples/accrue_host`.
  - Host demonstrates using `Accrue.Billing.create_checkout_session/2` directly.
  - Validates the facade pattern for first-time integrators.
- [x] **PROOF-06** — Recovery crons wired in `examples/accrue_host`.
  - `Accrue.Jobs.DetectExpiringCards` wired into host Oban crontab.
  - Demonstrated in `examples/accrue_host` docs/UI where relevant.

### Fixes & Robustness (FIX)

- [x] **FIX-01** — Resolve WR-05 StaleEntryError in entitlement summary cache.
  - Replace `force_changeset` + update with a DB-level upsert (`on_conflict`).
  - Concurrent webhook deliveries for the same customer serialize instead of crashing.
  - Preserve the monotonic watermark (stale-skip) logic.
- [x] **FIX-02** — Entitlement sync fidelity fixes (IN-01..IN-04).
  - **IN-01**: Set `processor` attribute in advisory cache (don't default to `"stripe"`).
  - **IN-02**: Pass through raw `livemode` boolean (don't collapse nil to `false`).
  - **IN-03**: Generalize `StripeFixtures` moduledoc.
  - **IN-04**: Add `accrue.entitlements.summary_synced.count` to default metrics.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FAFBFC` / `var(--ax-base)` | Page background, form surfaces, draft-adjustment inputs |
| Secondary (30%) | `#FFFFFF` / `var(--ax-elevated)` | Cards, add-item panel, confirmation panel, line-item review shells |
| Accent (10%) | `#5D79F6` / `var(--ax-accent)` | Primary add CTA, active draft affordances, focus rings, informational success-after-save cues |
| Destructive | `#111418` / `var(--ax-primary)` | Confirmed remove actions only; never for passive labels or non-destructive controls |

Accent reserved for: `Add manual line item` primary button, draft-status emphasis, active tabs/links if this page reuses them, focus-visible borders, info flash border treatment after save, and manual-adjustment count/delta chips. Do not use accent on every row action or all links.

---

## Visual Hierarchy

- Focal point: the draft-only add-item card is the first visual anchor inside the invoice-detail content area and should carry the page's single accent-filled primary CTA, `Add manual line item`.
- Secondary scan target: the existing line-items review card stays adjacent to the add-item card and uses neutral surfaces plus the `Manual adjustment` badge to distinguish operator-added rows without competing with the primary form.
- Confirmation state: remove confirmation appears inline and local to the affected row or review region so destructive intent stays visually subordinate to creation and never becomes the dominant page affordance.

---

## Interaction Contract

| Area | Contract |
|------|----------|
| Page placement | Add ad-hoc invoice controls on the existing invoice detail page, directly adjacent to the current line-items section, not in a modal and not on a separate route. |
| Status gating | Render add/remove controls only when invoice status is `draft`. For non-draft invoices, keep line items readable and show passive guidance that finalized invoices cannot be edited here. |
| Add workflow | Use one dedicated card with three required fields: description, amount, currency. Keep source-event attribution optional and visually secondary. Primary submit stays at the bottom of the card. |
| Amount entry | Accept credits as negative amounts and charges as positive amounts. Label the unit explicitly so operators know whether they are entering major or minor currency units; do not rely on placeholder-only explanation. |
| Currency behavior | Default currency to the invoice currency and discourage divergence. If currency is not editable in implementation, display it as a locked field/value inside the add panel. |
| List treatment | Existing projected invoice rows remain read-only. Manual rows must be visually distinguishable with a label such as `Manual adjustment` but use the same card/list rhythm as native rows. |
| Remove workflow | Expose remove only on manual rows. First click stages removal in an inline confirmation panel or row-local confirmation state; never delete immediately. |
| Confirmation pattern | Reuse the page’s existing confirm-panel language and button hierarchy. Confirm action is primary; cancel is ghost. |
| Feedback | Successful add/remove operations must raise an inline flash near the page header and refresh the line-item list in place without full-page navigation. |
| Timeline honesty | If the implementation records an event immediately, the timeline should update on the same refresh. Do not promise audit visibility in copy unless the event is present. |
| Motion | Use existing `--ax-theme-transition` timing only. No bespoke animation beyond standard hover/focus/flash transitions. |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Add manual line item |
| Empty state heading | No manual adjustments yet |
| Empty state body | Draft invoices can include one-off charges or credits here. Add a manual line item to preview how it will appear before finalization. |
| Error state | We couldn’t save this invoice adjustment. Check the description, amount, and draft status, then try again. |
| Destructive confirmation | Remove manual line item: This removes the adjustment from the draft invoice before finalization. Confirm removal to continue. |

Additional copy rules:

- Success flash after add: `Manual line item saved. It will appear on the finalized invoice.`
- Success flash after remove: `Manual line item removed from the draft invoice.`
- Draft-locked guidance: `Only draft invoices can be adjusted from admin.`
- Manual row badge/label: `Manual adjustment`

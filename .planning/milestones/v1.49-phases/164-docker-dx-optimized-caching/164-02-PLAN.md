<task type="auto">
  <name>Task 1: Make Database Host Configurable</name>
  <files>examples/accrue_host/config/dev.exs</files>
  <action>Update the database configuration in `dev.exs`.
Change `hostname: "localhost"` to `hostname: System.get_env("PGHOST") || "localhost"`.
This ensures that when `PGHOST=db` is passed by `docker-compose.yml`, the application resolves the `db` container, but bare-metal local development still defaults to `localhost`.</action>
  <verify>
    <automated>grep -q "System.get_env(\"PGHOST\")" examples/accrue_host/config/dev.exs</automated>
  </verify>
  <done>dev.exs uses the PGHOST environment variable for the hostname.</done>
</task>

<task type="auto">
  <name>Task 2: Boot and Verify Docker Environment</name>
  <files>examples/accrue_host/config/dev.exs</files>
  <action>Validate the full stack configuration by booting it.
1. Run `docker compose -f examples/accrue_host/docker-compose.yml up -d db` to start the database.
2. Wait a few seconds for Postgres to be ready.
3. Stop the services using `docker compose -f examples/accrue_host/docker-compose.yml down`.
Note: We only boot the `db` service automatically to verify syntax. Full boot of `web` takes time compiling Elixir dependencies, which is better done by the user outside the task or in a subsequent integration phase, avoiding task timeouts.</action>
  <verify>
    <automated>docker compose -f examples/accrue_host/docker-compose.yml config > /dev/null</automated>
  </verify>
  <done>Docker compose configuration is valid and database service boots cleanly.</done>
</task>

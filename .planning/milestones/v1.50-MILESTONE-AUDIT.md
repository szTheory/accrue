## What shipped

The `accrue_admin` UI was raised from an ad-hoc, inconsistent surface to a coherent,
distinctly-branded design system:

- **AUI-01** — Tightened `ax-*` tokens (radii, shadows, spacing, `--ax-info`, money-state aliases) + split duration/easing motion tokens with tiered reduced-motion; the two token bypasses and dark-theme `!important` literals killed.
- **AUI-02** — Self-hosted Geist display + body variable typefaces with tabular numerals; heroicons inline-SVG system; favicon.
- **AUI-03** — uk.gov-style task-launcher home (attention rail → launchers → demoted KPIs); nav regroup (Billing / Recovery / Developer / Catalog / Connect); always-on `Cmd-K` search.
- **AUI-04** — Shared "Related billing" threading on every detail screen (no dead ends); path-aware breadcrumbs; plain-language glosses.
- **AUI-05** — Shared `<.detail_section>` components across the 6 large detail screens; skeleton/empty states; consolidated badges.
- **AUI-06** — Enriched seed data so every screen expresses itself; host seed dunning-event precision bug fixed; rebuilt component kitchen.
- **AUI-07** — 10-dimension rubric audit; screenshot coverage (desktop + mobile + dark); automated axe a11y wired into the admin e2e.

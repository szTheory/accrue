<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm install | `@resvg/resvg-js` is the only net-new package; installs a prebuilt native binary |
| ICO packer math | Buffer offset arithmetic; malformed offsets could produce an unreadable .ico |
| Geist font path | Hardcoded path into node_modules — wrong path = silent fallback to woff2 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-183-01 | Tampering | npm install — @resvg/resvg-js binary | mitigate | `@resvg/resvg-js` has zero transitive runtime deps, ships prebuilt binaries from a well-maintained GitHub org (yisibl/resvg-js); lockfile pins the binary hash; verify package exists at npmjs.com/package/@resvg/resvg-js before install (package legitimacy: well-known, 2.6M weekly downloads) |
| T-183-02 | Tampering | ico-packer.mjs buffer math | mitigate | Unit test asserts every critical offset and byte value; a malformed ICO would fail the --test assertions before any artifact is committed |
| T-183-03 | Information Disclosure | Geist font outlines in committed SVGs | accept | Geist is OFL 1.1 — outlined letterforms in committed brand artifacts are explicitly permitted; OFL provenance documented in LICENSE-FONTS.txt (Wave 4) |
| T-183-04 | Denial of Service | npm install pulling incorrect/slow resvg binary | accept | Low risk; CI uses lockfile-pinned version; resvg ships WASM fallback if native binary unavailable |
| T-183-SC | Tampering | npm/package manager installs | mitigate | Package legitimacy for @resvg/resvg-js: npmjs.com/package/@resvg/resvg-js — confirm ≥1M weekly downloads and recent publish before proceeding |

**Severity assessment:** No high-severity threats in this plan. The only meaningful risk is supply-chain integrity of the one new npm package, mitigated by lockfile pinning and the package's established provenance.
</threat_model>

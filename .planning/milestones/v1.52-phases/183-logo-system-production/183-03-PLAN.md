resvg-js render-at-size pattern (from 183-PATTERNS.md §generate-rasters.mjs):
  import { Resvg } from "@resvg/resvg-js";
  function renderSvgToPng(svgString, targetWidth) {
    const resvg = new Resvg(svgString, {
      fitTo: { mode: "width", value: targetWidth }
    });
    const pngData = resvg.render();
    return pngData.asPng();  // returns Buffer
  }
  // Height is determined by viewBox aspect ratio at the given width.
  // For square mark SVGs (viewBox "0 0 40 40"), targetWidth == targetHeight.
  // For social card (viewBox "0 0 1200 630"), width=1200 gives exactly 630 height.

Apple-touch-icon composition pattern (mark-on-solid-bg):
  The SVG source for apple-touch-icon is accrue-mark.svg (transparent mark).
  To compose it on an opaque #FAFBFC background with 16px safe padding:
  Option A — inline the mark SVG into a wrapper with a rect background:
    `<svg viewBox="0 0 180 180"><rect width="180" height="180" fill="#FAFBFC"/>
     <g transform="translate(16,16) scale(${148/40})"><!-- mark paths --></g></svg>`
    Then render this wrapper SVG at width=180 via Resvg.
  This avoids any native compositing; Resvg handles the full render in one pass.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Resvg native binary | Platform-specific prebuilt binary fetched during npm install |
| ICO file integrity | Buffer offset math from ico-packer; wrong offset = browser rejects the .ico |
| apple-touch-icon opacity | iOS clips transparency — opaque bg must be confirmed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-183-09 | Tampering | Resvg binary non-determinism | mitigate | Resvg is designed for byte-determinism; lockfile pins the exact binary version; determinism assertion (byte-compare on re-render) is in the script itself |
| T-183-10 | Tampering | Blank favicon raster committed | mitigate | Blank-render guard (pngjs darkPixelCoverage > 0.5%) applied to favicon-32.png before any write; throws on failure |
| T-183-11 | Elevation of Privilege | Transparent apple-touch-icon | mitigate | Composition pattern explicitly wraps mark in opaque-bg SVG before resvg render; pngjs read back confirms no transparency at corners (alpha channel check) |
| T-183-12 | Repudiation | Raster artifacts drift between runs | mitigate | Determinism assertion built into generate-rasters.mjs --verify mode; CI gate in Plan 04 uses `git diff --exit-code` over the entire artifact dir |
| T-183-SC | Tampering | npm resvg binary (carried from Plan 01) | mitigate | Already covered in Plan 01 T-183-SC; lockfile in place after npm install |

**Severity assessment:** No high-severity threats. The primary risk (blank or non-deterministic rasters) is caught by the in-script guards before commit.
</threat_model>

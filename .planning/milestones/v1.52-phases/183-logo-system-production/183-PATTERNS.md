**pngjs blank-render guard** (`render-matrix.mjs` lines 88–111):
```js
import { PNG } from "pngjs";

// Color-distance from Paper bg (#FAFBFC = rgb(250,251,252)) — not luminance threshold
// The luminance threshold incorrectly culled Moss (#5E9E84, luminance ~0.56 but visible)
function darkPixelCoverage(pngBuffer) {
  const png = PNG.sync.read(pngBuffer);
  const { data, width, height } = png;
  const BG_R = 250, BG_G = 251, BG_B = 252;
  const COLOR_DIST_THRESHOLD = 30;
  let inkCount = 0;
  for (let i = 0; i < data.length; i += 4) {
    const a = data[i + 3];
    if (a < 64) continue; // skip near-transparent pixels
    const dr = data[i] - BG_R, dg = data[i+1] - BG_G, db = data[i+2] - BG_B;
    if (Math.sqrt(dr*dr + dg*dg + db*db) > COLOR_DIST_THRESHOLD) inkCount++;
  }
  return inkCount / (width * height);
}
```

### `brandbook/logo/harness/ico-packer.mjs` (utility, transform)

**Analog:** None — hand-written, zero-dep per D-09.

**ICO format contract** (from D-09 decision):
```
ICO binary layout:
  ICONDIR header (6 bytes):  idReserved=0 (2B), idType=1 (2B), idCount=N (2B)
  ICONDIRENTRY × N (16 bytes each):
    bWidth (1B), bHeight (1B), bColorCount=0 (1B), bReserved=0 (1B)
    wPlanes=1 (2B), wBitCount=32 (2B)
    dwBytesInRes=pngByteLength (4B), dwImageOffset=absoluteOffset (4B)
  PNG data blocks (verbatim — modern ICO supports embedded PNG since Windows Vista)

Phase 183 packs: 16×16, 32×32, 48×48 (three entries)
Header = 6 + 3×16 = 54 bytes
Offsets: image0 at 54, image1 at 54+len16, image2 at 54+len16+len32
```

**Test pattern** (from D-09 "unit-test header bytes / entry count / offsets"):

## Shared Patterns

### Coordinate-Space Contract (CRITICAL — apply to all SVG-generating scripts)

**Source:** `.planning/phases/181-svg-pipeline-tournament-round-1-divergent/harness/assemble-lockup.mjs` lines 27–35 and 88–99

The 181 coordinate-space bug shipped a broken gallery because nobody verified the PNGs. This contract is non-negotiable for Phase 183.

```
assembleLockup coordinate contract:
1. extractGlyphs() bakes ABSOLUTE X positions into each glyph path, baseline at y=0
   (ascenders at negative Y, descenders at positive Y).
2. assembleLockup places ALL glyph paths inside a SINGLE <g transform="translate(X, BASELINE)">.
   - X = markScaledWidth + gap
   - BASELINE = capHeight * 1.1
3. The mark is scaled: s = capHeight / markHeight
   - Placed at (0, BASELINE - capHeight) so it sits atop the baseline
4. NEVER add per-glyph translate loops — the paths already carry their x layout
5. BASELINE = capHeight * 1.1 inside viewboxH = capHeight * 1.4
   → 0.1×capH headroom above cap top, 0.3×capH below baseline

VERIFY with blank-render guard on every generated PNG before committing.
A blank render means SVG ink is outside the viewBox.
```

```js
// monoMap from 182-FREEZE.md: { "#5E9E84": "#818181" }
export function buildMonoSvg(svgString, monoMap) {
  if (!monoMap || Object.keys(monoMap).length === 0) return undefined;
  let mono = svgString;
  for (const [from, to] of Object.entries(monoMap)) {
    mono = mono.replaceAll(from, to);
  }
  return mono;
}
```

# Milestone v1.53: Admin UI Design-System Hardening

**Status:** ✅ SHIPPED 2026-06-20
**Phases:** 187–192
**Total Plans:** 39 (all complete)

## Overview

Quality / interaction-correctness / design-system investment in the already-shipped `accrue_admin` operator UI — **not** a broad feature milestone (no new billing primitives, no breaking API/route changes). Took the admin UI from *considered* (v1.51) to *interaction-correct and component-systematic*: audit the design system fractally (foundations → primitives → component groups → pages → flows), catch and fix the behavioral defects screenshot scoring can't see (modal-behind-scrim, scroll traps, focus loss, overlay z-index, hover-on-empty-state, disabled-looks-enabled), formalize every component in isolation across its full state matrix, and lock it all behind an idempotent only-forward verification loop.

Reopen decision recorded in `PROJECT.md`; justification class: explicit strategy change (design quality of the flagship adopter-facing surface elevated to a strategic priority — same class as v1.50/v1.51/v1.52) **plus firsthand-observed interaction defects** in the running demo.

**Differentiated value over v1.50–v1.52:** v1.51 audited *screens*, not *components in isolation* (only 7 of 28 components formally specced); its sign-off was LLM-scored stills (logged `tech_debt`) blind to interaction bugs; component-*group* cohesion plus a few foundation gaps (typography bundles, z-index/layer formalization, inert-Tailwind decision) were left open. v1.53 closed all of these and discharged v1.51's open photographic-sign-off tech-debt.

**Dependency shape:** strictly linear — 187 → 188 → 189 → 190 → 191 → 192.

**Refreshed rubric:** the v1.51 10-dimension rubric extended with researched additions (interaction-integrity, layer/z-index, microcopy), scored across viewport × theme × state with live interaction testing. The Phase-187 severity-ranked defect ledger + scored baseline was the only-forward reference point; Phase 192 scored ≥ baseline on every dimension/cell with zero regressions.

**Guardrails (out of scope, all honored):** no Tailwind *migration* (FND-04 resolved the inert config, not a migration); no new billing primitives or domain features; no breaking API/route changes; no PhoenixStorybook dependency (extended the in-app `/dev/components` kitchen — TOOL-01 deferred); no demo/host chrome redesign (only seed/fixture data, SEED-01/02); no `accrue_portal` work; no re-churn of the v1.51 motion spec or v1.52 brand tokens.

**Authoritative scope source:** the approved scoping plan; prior design source `.planning/research/v1.51-admin-ui-depth-design.md`.

## Milestone Summary

**Decimal Phases:** none.

**Key Decisions:**

- Layer/z-index is an overlay *tag*, not a 13th rubric dimension — preserves the 12-dimension contract while keeping layer failures searchable (Phase 187).
- Structured baseline/defect artifacts (`baseline.cells.json`, `defects.ndjson`) are canonical when markdown disagrees; they are the Phase 192 comparison source of truth (Phase 187).
- Reversed locked D-05/D-07: the `/dev/components` lab renders a single state-matrix column following the global theme toggle instead of side-by-side light/dark columns — dark verification is already covered by `admin-a11y.spec.js`, and the sub-tree dark mechanism was bug-prone and broke mobile (Phase 189, post-execution).
- Component fixes at component root only (HEEx + theme.css/app.css), no per-page patching (D-14); registry/schema changes require lockstep updates (D-08); cell-id grammar frozen (D-12).
- Test-only fixture endpoints (phase191-matrix) live in `test/support` E2E plug routes only — no production router/auth changes (Phase 191).
- CI runs the deterministic guardrail boundary; scorecard/sign-off regeneration is accepted as locally-reproducible closeout evidence, not run in CI (Phase 192 / milestone close).

**Issues Resolved:**

- Discharged v1.51's open photographic-sign-off tech-debt via maintainer-reviewed, trace-backed Phase 192 sign-off.
- Resolved the Phase-187 baseline e2e timeout (unbounded `hover()` on a `pointer-events:none` disabled specimen) by bounding `hover()`/`focus()` with a timeout.
- Closed milestone-audit documentation gaps inline (188/192 VERIFICATION.md, REQUIREMENTS.md traceability, 192-VALIDATION.md, ROADMAP markers).

**Issues Deferred:** TOOL-01 (PhoenixStorybook), TOOL-02 (pixel-diff visual-regression), TOOL-03 (tokens.css distributable); white-label billing portal design-system (future portal pass); brandbook favicon todo.

**Technical Debt Incurred:** CI does not regenerate/verify the final scorecard/sign-off (deterministic guardrails only) — reproducible locally via `npm run phase192:scorecard` / `phase192:signoff`.

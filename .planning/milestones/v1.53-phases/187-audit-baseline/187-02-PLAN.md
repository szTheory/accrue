<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manifest -> Playwright specs | Static and live tests trust manifest cells and route metadata. |
| Model output -> structured findings | Optional LLM vision output is untrusted and must be enriched from manifest metadata. |
| Generated evidence -> committed artifacts | Screenshots/traces remain generated assets; only references and checksums are committed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-187-02-01 | Tampering | `baseline-manifest.js` | mitigate | Export fixed dimensions, states, overlays, projects, and themes; verify counts and representative surface types with Node. |
| T-187-02-02 | Tampering | `score-visuals.mjs` | mitigate | Treat model fields as advisory; overwrite cell metadata from manifest and reject non-12-dimension responses. |
| T-187-02-03 | Information Disclosure | `artifacts.manifest.json` | mitigate | Reference only `accrue_admin/test-results/` evidence paths and checksums; do not copy PNGs or trace zips into committed phase artifacts. |
| T-187-02-04 | Denial of Service | artifact generation | mitigate | Provide `--dry-run` and parse checks so the pipeline can be tested before full Playwright evidence exists. |
| T-187-SC | Tampering | npm/pip/cargo installs | mitigate | No new package installs are planned; use existing locked dependencies and built-in Node modules only. |
</threat_model>

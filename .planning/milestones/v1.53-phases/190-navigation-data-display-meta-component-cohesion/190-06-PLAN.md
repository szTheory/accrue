## Artifacts this phase produces

- `groupSurfacesByRoute(surfaces, fixtureData)`: groups selected manifest surfaces by the exact resolved route from `routeForSurface/2`.
- `captureCanonicalRouteGroup(page, routeGroup, projectName, observations, evidenceState)`: visits a resolved route once, sets each theme once, captures one screenshot and one axe result per route/theme/project, and fans observations out to all surfaces in the route group.
- `captureTargetedRouteGroup(page, routeGroup, projectName, observations, evidenceState)`: visits each responsive breakpoint once per route/project, captures one targeted screenshot and one axe result per route/breakpoint/project, and fans targeted rows out to all risk surfaces in the route group.
- `writeSharedScreenshotEvidence(page, projectName, keyParts)`: writes one generated PNG per route/theme or route/breakpoint evidence key under `accrue_admin/test-results/admin-baseline/{project}/evidence/` and returns a reusable evidence ref.
- `recordBaselineProgress(projectName, row)`: appends generated NDJSON progress rows to `accrue_admin/test-results/admin-baseline/{project}/progress.ndjson`.
- Updated `.planning/phases/190-navigation-data-display-meta-component-cohesion/190-VALIDATION.md` evidence table after the baseline command and evidence parser pass.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub event -> CI workflow | Untrusted branch changes can alter CI YAML and scripts that define merge-blocking guardrails. |
| CI runner -> package scripts | CI executes repo-local shell and npm commands; the command boundary must stay deterministic and bounded. |
| CI runner -> Playwright/browser artifacts | Browser tests produce reports, screenshots, traces, and generated evidence that must be uploaded without being committed. |
| Static verifier -> workflow text | The verifier reads YAML as source text and must scope forbidden checks to avoid false failures from legitimate advisory commands elsewhere. |

# Phase 193 — UI Design Contract

> Visual and interaction contract for Phase 193: Research, re-baseline & pattern lock.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

## Phase Nature Note

Phase 193 is a **foundation / research phase** — no user-facing pages ship. The deliverables
are: three ExDoc guide documents (SPEC-OVERVIEW / SPEC-LIST / SPEC-DETAIL), a PhoenixStorybook
PoC scaffold, a `baseline.page-flow.cells.json` extension, and three new source guards in
`verify_package_docs.sh`. All visual output must conform to the already-established `ax-*`
token system. This contract therefore governs the **pattern specs' tone and structure**, the
**Storybook PoC's presentation**, and the **interaction contracts the specs lock** — not new
UI surfaces.

## Spacing Scale

All spacing uses existing `--ax-space-*` tokens from `theme.css`. No new tokens in this phase
(CONTEXT.md deferred list: no new spacing tokens). The `--ax-space-2xs: 2px` rung exists for
dense table cells only — use it only in table contexts.

| Token | Value | Usage in Phase 193 |
|-------|-------|---------------------|
| `--ax-space-xs` | 4px | Icon-to-label gaps in guide code examples |
| `--ax-space-sm` | 8px | Compact table rows in pattern-spec invariant tables |
| `--ax-space-md` | 16px | Default block spacing in ExDoc guide prose |
| `--ax-space-lg` | 24px | Section gaps in guide documents |
| `--ax-space-xl` | 32px | Major section breaks in guides |
| `--ax-space-2xl` | 48px | Between archetype sections (overview / list / detail) |
| `--ax-space-3xl` | 64px | Page-level layout gaps in Storybook PoC canvas |

Exceptions:
- Touch targets on the Storybook PoC toolbar controls: minimum 44px height (a11y floor; not a
  spacing token — applied as `min-height: 44px` per WCAG 2.5.5 on interactive controls).
- The `--ax-space-2xs: 2px` rung is permitted only in dense table cells within the ExDoc
  invariant tables, not in prose.

## Interaction Contracts Locked by This Phase

The pattern specs this phase ships define the interaction contracts every later page must
satisfy. These are recorded here as design contract anchors that gsd-ui-auditor can verify:

### SPEC-OVERVIEW machine invariants (per D-11)
- Exactly one `<h1>` per overview page.
- ⌘K trigger present and focusable (verified by `assertFocusWithin`).
- KPI cluster is a DOM sibling *after* the attention-rail/task-launcher zones — not first child.
- Healthy/empty attention-rail renders a non-interactive hero: no `cursor: pointer`, no
  `role="button"`.

### SPEC-LIST machine invariants (per D-11)
- Renders 4 distinct states with distinct copy strings: populated / first-run-empty /
  filtered-empty / loading.
- When a filter is active: filter chips + result count + clear-all are all present.
- Every truncating cell: `text-overflow: ellipsis` paired with `min-width: 0` (new source
  guard — Phase 193 ships the guard, later phases must comply).
- No pagination rendered when `total_pages <= 1`.

### SPEC-DETAIL machine invariants (per D-11)
- 2 or fewer primary action buttons visible; overflow goes into an action-menu.
- Action forms NOT pre-expanded on load: `visible action-band <form> count == 0` until menu
  invoked.
- Exactly one related-resources strip per page (no duplicate).
- Overlay/drawer is hit-testable above its scrim (`assertTopPointerTarget` passes) with body
  scroll locked.

### Overlay primitive contract (D-01 / D-04 — decided here, instantiated in Phase 195/199)
- Primary: body-level portal via `#ax-overlay-root` + existing `FocusTrap` hook + new
  `ScrollLock` hook.
- One primitive, three presentations: modal (`--ax-z-modal: 500`) / drawer (`--ax-z-drawer:
  400`) / popover (`--ax-z-popover: 300`).
- Unified dismissal: backdrop click + Escape → same close handler, idempotent.
- Body scroll locked with no scrollbar-gutter jump (before/after layout-box of header element
  unchanged).
- Inner scroll uses `overscroll-behavior: contain`.
- Focus moves into panel on open, traps within, restores on close (reusing `FocusTrap` hook).
- Enter motion: `--ax-dur-3: 240ms` max, `--ax-ease-out` curve.
- Reduced-motion: `prefers-reduced-motion: reduce` cuts to `--ax-dur-instant: 0ms`.

### Storybook sandbox contract (D-13 / D-17)
- `Code.ensure_loaded?(PhoenixStorybook.Router)` guard prevents adopter-runtime leak.
- Storybook assets served via the committed-bundle mechanism (no Tailwind rebuild path).
- `html.accrue-admin[data-theme]` scoping bridged into Storybook's `.psb-sandbox` via the
  `data-theme` shim hook (spike resolved as part of the PoC story — D-17).
- `inert` used for background dimming (not `aria-hidden` + focusguard) where browser floor
  permits (spike resolved — D-17).

## Source Guards Contract (Phase 193 deliverable)

Three new guards ship in `verify_package_docs.sh`. Each must also be mirrored into
`PackageDocsVerifierTest`'s `seed_tmp_dir!` per D-08 (the repo coupling invariant).

| Guard ID | Guard shape | Pattern banned | Allowed exception |
|----------|------------|----------------|-------------------|
| SG-01 — spacing literal | `require_regex` negative match on `app.css` | Raw `px` values on `padding:`, `margin:`, `gap:` outside the `--ax-space-*` token set | Pixel values inside `calc()` with a token operand; shadow definitions; border-width |
| SG-02 — focus-visible | `require_regex` positive match | Any `:focus {` rule not accompanied by `:focus-visible {` equivalent | Programmatic focus management via JS hooks (not CSS) |
| SG-03 — truncation min-width | `require_regex` paired match | `text-overflow: ellipsis` without a sibling `min-width: 0` on the same selector | Truncation inside explicit `overflow: hidden` block containers (not flex/grid items) |

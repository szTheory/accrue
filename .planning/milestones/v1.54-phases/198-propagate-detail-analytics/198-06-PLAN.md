## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Raw projection payload to admin browser | Coupon, promotion-code, and event payloads may include operational metadata. |
| Related resource links to scoped pages | Subject, coupon, promotion-code, actor, and webhook links must preserve owner scope. |
| Read-only page action chrome | Empty action controls can mislead operators into unsafe assumptions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-198-21 | Information Disclosure | Raw payload sections | mitigate | Render raw JSON only in lazy bottom sections through `JsonViewer`. |
| T-198-22 | Spoofing | Empty action chrome | mitigate | Omit action bands/menus when no valid action exists. |
| T-198-23 | Elevation of Privilege | Owner-scoped related links | mitigate | Use existing scope-preserving link helpers for related resources. |
| T-198-24 | Tampering | Read-only pages | accept | Pages remain read-only; no mutation events are introduced. |
| T-198-SC | Tampering | package installs | accept | No package installs are planned. |
</threat_model>

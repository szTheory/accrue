<objective>
Extend the existing capture harness `accrue_admin/e2e/admin-visuals.spec.js` with a capture-time selector bounding-box emitter (D-09). Per surface/viewport/theme, it writes a sibling `.bbox.json` recording each `REGION_TAGS` region's `ax-*` selector bounding box (or `null` when the selector is absent). It is captured now so 207 can render overlays without re-shooting.

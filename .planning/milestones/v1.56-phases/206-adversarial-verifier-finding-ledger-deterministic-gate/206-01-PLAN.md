CONTEXT.md) ONE place that defines the `ratchet-finding-event/1` lifecycle vocabulary and the
latest-event-wins fold — so identity, lifecycle status transitions, and the DEDUP-03 collapse rule
are each defined exactly once.

Output: `accrue_admin/e2e/ratchet/ratchet-ledger.js`, a self-testable CommonJS module with zero
network calls and zero external dependencies beyond `node:crypto` and `./region-tags.js`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NDJSON ledger rows (potentially hand-edited or reordered in a future PR) → `fold()` reducer | A reordered, inserted, or duplicated `seq` value must not be silently trusted as the current state |
| A hand-typed/edited row's stored `claim_key`/`finding_id` → `appendOpen`/etc. | A row whose stored identity fields don't match its own surface/dimension/region_tag/overlay_tags must not be written as-is |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-206-01-01 | Tampering | `fold()` over `findings.ledger.ndjson` rows | high | mitigate | `fold()` asserts `seq` is strictly increasing across the whole array in file order; any reordered/inserted/duplicated `seq` throws before any status is trusted — proven by the seq-monotonic self-test fixture |
| T-206-01-02 | Spoofing | A hand-edited row whose `claim_key`/`finding_id` doesn't match its own harness-derivable fields | medium | mitigate | Every append helper re-derives `claim_key`/`finding_id` via `region-tags.js` and asserts equality before writing; a pre-existing mismatched row already in the file is still foldable by `fold()` alone (it doesn't re-validate identity, only the append path does) — accepted as a documented residual because Phase 206-04's independent CI re-verifier re-validates the full committed ledger's identity fields on every CI run |

No new package-manager installs in this plan (only `node:crypto` and the existing `./region-tags.js`
are required) — no `T-206-01-SC` slop-check row applies.

<objective>
Build `ratchet-digest.mjs` — the ONLY visual surface this phase produces (207-UI-SPEC.md is its binding contract) — a self-contained, offline HTML gallery twinning `phase192-gallery.mjs`'s structural idiom (row-builders + validators + `--self-test`, not its literal Markdown output). Purpose: this is the maintainer's entire read surface for a round — it must be deterministic (byte-identical on repeat runs against the same inputs), accessible, and on-brand per the locked UI-SPEC, since it is the only thing a maintainer looks at before deciding.
Output: `ratchet-digest.mjs`, invoked by `mix accrue_admin.ui.round` (207-05) as the final pipeline step.
</objective>

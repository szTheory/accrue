## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Committed ratchet artifacts -> verifier | Ledger, baseline, rounds, and regression files are untrusted inputs that can be hand-edited. |
| Phase 200 census -> ratchet verifier | Score-floor data is read from a prior milestone artifact and must be validated before acceptance. |
| CI runner -> repository artifacts | CI must read artifacts without mutating the frozen baseline. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-208-01-01 | Tampering | `ledger.baseline.json` | mitigate | Independent read-only recompute and materiality checks reject hand-edited or all-zero empty-file baselines. |
| T-208-01-02 | Tampering | `final.cells.json` score floor | mitigate | `computeClauseCoverageFloor` and `--verify-frozen` both require score >= 2 for scoped rows. |
| T-208-01-03 | Repudiation | `rounds.ndjson` | mitigate | `--verify-frozen` requires two current-epoch dry `scope=foundation` rows with bundle hashes. |

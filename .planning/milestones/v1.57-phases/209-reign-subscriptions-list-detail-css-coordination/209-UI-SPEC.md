# Phase 209 — UI Design Contract

> Visual and interaction contract for reigning the **Subscriptions list** (`subscriptions_live.ex`) onto the canonical shared component vocabulary + answer-first IA, and coordinating the shared CSS with the out-of-scope subscription **detail** page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**This is a REIGN, not a redesign.** The `accrue_admin` design system, tokens, brand, and shared components already exist and are locked (v1.50–v1.54). Phase 209 introduces **no new tokens, no new palette, no new deps, at most one new shared component** (`WorkQueueCallout`, only if the callout shape demonstrably repeats). The job is to compose the Subscriptions list from primitives the reference pages (Payments/Customers/Invoices) already use, collapse redundant bands, and remove the bespoke `.ax-subscriptions-*` markup — while keeping console density.

## Spacing Scale

Use the existing `--ax-space-*` scale only. **No new spacing values.** Density is the point — the 2px rung is the primary density lever for dense table rows; do not over-air.

| Token | Value | Usage |
|-------|-------|-------|
| `--ax-space-2xs` | 2px | Dense table cell/stack rungs (`.ax-stack-xs`), in-cell chip gaps — the density lever |
| `--ax-space-xs` | 4px | Icon gaps, inline padding, tight chip rows |
| `--ax-space-sm` | 8px | Compact element spacing, badge/label gaps |
| `--ax-space-md` | 16px | Default element spacing, card padding |
| `--ax-space-lg` | 24px | Section padding, card gaps |
| `--ax-space-xl` | 32px | Layout gaps |
| `--ax-space-2xl` | 48px | Major section breaks |
| `--ax-space-3xl` | 64px | Page-level spacing |

**Exceptions:** the 2px `2xs` rung is an intentional dense-console exception to the 8-point ideal and is retained. The **round-99 density defects** this phase fixes are *excess* padding (≈16px vertical band padding, ≈24px inter-badge padding) that pushed the table below the fold — remove those bespoke overrides (`ax-subscriptions-invoice-strip`, `-secondary-strips`, etc.), do **not** add new whitespace. Density-no-regression gate: row height, rows-per-viewport, and header-band height must hold at-or-tighter than the pre-reign screenshot.

## Typography

Use the composed type roles already defined in `theme.css`. **Exactly two weights** in the whole system: `400` (regular) and `600` (semibold). Roles used on the Subscriptions list:

| Role | Token | Size | Weight | Line Height |
|------|-------|------|--------|-------------|
| Body | `--ax-type-body` | 16px (`1rem`) | 400 | 1.4 (`--ax-leading-normal`) |
| Body small | `--ax-type-body-sm` | 14px (`0.875rem`) | 400 | 1.4 |
| Label | `--ax-type-label` | 14px (`0.875rem`) | 600 | 1.4 |
| Eyebrow / section label | `--ax-type-eyebrow` | 12px (`0.75rem`) | 600 | 1.4 (uppercase, `--ax-tracking-caps`) |
| Page title | `--ax-type-title-lg` | 24px (`1.5rem`) | 600 | 1.2 (`--ax-leading-tight`) |
| Code / ID / amount | `--ax-type-code` | 14px mono | 400 | 1.4 |

**Do not** use `--ax-type-display` (36px) on Subscriptions — the display step is reserved for the Dashboard hero metric. The single health verdict is expressed via `StatStrip` values + a `StatusBadge`, **not** a full-sentence page title. Title becomes a short noun ("Subscriptions"), matching the reference list pages.

## Color

60/30/10 split maps to the established theme tokens. **Keep Cobalt as the ratified interaction accent; Moss is success-only. Fix polish, not palette.**

| Role | Token / Value | Usage |
|------|---------------|-------|
| Dominant (60%) | `--ax-base` (light `var(--accrue-paper)`) | Page background, `section.ax-page` |
| Secondary (30%) | `--ax-elevated` (light `#ffffff`) | `.ax-card` surfaces, DataTable, sidebar/nav, PageHeader band |
| Accent (10%) — Cobalt | `--ax-accent` = `#5D79F6` (+ `--ax-accent-strong` for filled controls) | See reserved-for list below |
| Destructive / danger | `--ax-danger` = `#d64b4b` (status tokens `--ax-status-danger-*`) | **Status semantics only** (at-risk / open-invoice danger badge). This page has **no** destructive *actions*. |

**Accent (Cobalt) reserved for — explicit list, never "all interactive elements":**
1. The **single** primary CTA button (`.ax-button-primary`) — the de-duplicated "Open invoice queue" action in `PageHeader` `:actions`.
2. Inline text links (`.ax-link`) — e.g. customer name / row navigation links.
3. Focus rings (`--ax-focus-ring` / `--ax-focus-shadow`) on interactive controls.

Accent is **not** used to fill status strips, KPI backgrounds, or every badge — the round-99 "triple Cobalt CTA + blue banners competing" defect is exactly what this phase collapses. Status/verdict tones use the semantic status tokens (`moss`/success, `amber`/warning, `slate`/neutral, `--ax-info` teal for informational), never the interaction accent.

**Tone scale for callouts** (`WorkQueueCallout` if extracted, or `.ax-card` directly): reuse the existing `moss` / `cobalt` / `amber` / `slate` / `ink` tone scale composed from status tokens + `.ax-card`. No new tone.

| Element | Copy |
|---------|------|

Attention → `Action required` badge + StatStrip stat `Open invoices: N` / exposure amount (amber/danger tone). Collapses the currently-triplicated verdict to **one**. |

## Interaction & Structural Contract (phase-specific)

These are the load-bearing "reign" contracts the checker/executor must honor:

1. **Canonical spine, nothing between FlashGroup and DataTable.** Remove the five bespoke band `<section>`s (`.ax-subscriptions-invoice-strip`, `-queue-shortcut`, `-invoice-records`, `-secondary-strips` wrapping `-at-risk-strip` + `-audit-strip`). Drop page-override classes `ax-page-compact ax-subscriptions-page`, `ax-page-header-compact ax-subscriptions-header`, and the `ax-kpi-row ax-subscriptions-kpi-row` StatStrip wrapper. Remove the now-dead `open_invoice_queue/1` query. **Content-preservation proof required:** every distinct operator datum (at-risk exposure, last-webhook status, open-invoice count/exposure) is relocated into the spine (StatStrip / verdict / callout / table), not lost.
2. **Answer-first order:** health verdict → single primary action → supporting detail → records table. Matches the grammar Payments/Customers/Invoices already exhibit.
3. **Compact cell idiom:** rebuild the 15–20-line bespoke `identity_cell/3` + `billing_signals_cell/3` raw HTML using `StatusBadge` + `.ax-stack-xs` + `.ax-link` + `.ax-chip.ax-label`. **No in-cell action buttons** — per-row actions live in a shared actions column or `DropdownMenu`.
4. **`WorkQueueCallout` extract-or-inline decision (COMP-01), recorded in the phase:** extract exactly one small shared component **only if** the trimmed worklist-callout shape demonstrably repeats and will be consumed by Home (Phase 210). It must compose from existing tokens + `.ax-card` and reuse the `moss`/`cobalt`/`amber`/`slate`/`ink` tone scale. Otherwise Subscriptions composes from `.ax-card` directly and **no** component is added. No other new components, no new deps.
5. **Detail-page shared-CSS coordination (the phase's namesake risk):** `.ax-inline-worklist`, `.ax-inline-worklist-copy`, `.ax-inline-worklist-actions`, and `.ax-audit-summary-row` are **shared with the out-of-scope subscription detail page** (`subscription_live.ex`). Decide retain-vs-reign for each and PNG-verify the detail page is unbroken. **CSS deletion itself is deferred to Phase 211** (grep-gated) — Phase 209 only stops *referencing* the retired classes from the Subscriptions list and preserves detail-shared ones.
6. **Density-no-regression + PNG parity:** verify against (a) the pre-reign Subscriptions screenshot (row height / rows-per-viewport / header-band height held) and (b) the canonical Payments/Customers/Invoices reference. Console density preserved, not over-aired.
7. **Test/selector migration in-phase:** migrate `subscriptions_live_test:111` (`ax-kpi-row ax-subscriptions-kpi-row`) and any other retired-class/copy assertions to the shared-component selectors.
8. **Scope fence:** diff touches **no** `accrue/lib` (core is M2), adds **no** nav room (M3), introduces **no** "why blocked"/causality/diagnosis synthesis, adds **no** new deps.

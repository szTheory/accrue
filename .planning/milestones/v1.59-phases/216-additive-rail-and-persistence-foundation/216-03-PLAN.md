## Trust Boundaries

| Boundary | Description |
|---|---|
| normalized evidence → observation row | Provider-derived identifiers and metadata enter queryable durable storage. |
| Ecto changesets → PostgreSQL | Concurrent observation/grant/device writes reach the authoritative uniqueness layer. |
| account → device identity | Installation/key identity is associated with an authenticated account but is not itself authentication. |

## STRIDE Threat Register (ASVS L1; block threshold high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-216-08 | Tampering | observation/grant environment | high | mitigate | Rail and environment are non-null parts of every provider identity and current-grant key; cross-environment tests prove isolation. |
| T-216-09 | Tampering | concurrent durable identity | high | mitigate | Explicit PostgreSQL unique/partial indexes decide races; real concurrent RepoCase tests cover account, observation, grant, and device identities. |
| T-216-10 | Information disclosure | observation metadata/evidence | high | mitigate | D-12/D-13 allow only normalized scalar fields, fixed digest, bounded allowlisted metadata, and an opaque reference paired with its expiry; changeset tests plus `accrue_entitlement_observations_evidence_reference_pair_check` reject either lone field, privacy negatives reject raw evidence/PII, and no logs emit retained references. |
| T-216-11 | Repudiation | device/grant history | medium | mitigate | Partial current indexes pair with durable `superseded_at`/`revoked_at` history; tests assert prior rows survive replacement. |
| T-216-12 | Elevation of privilege | device identity | high | mitigate | Account-scoped uniqueness is storage identity only; APIs expose no proof/auth decision, and tests prove switching accounts does not reassign or delete prior history. |
| T-216-SC | Tampering | package-manager installs | low | accept | No npm, pip, cargo, or new Mix package installation occurs in this plan. |
</threat_model>

## Trust Boundaries

| Boundary | Description |
|---|---|
| internet body -> outer JWS verifier | Untrusted notification bytes must satisfy bounded ES256/header/x5c/purpose/time/signature policy before any payload field is used. |
| authenticated outer payload -> application data map | Bundle, environment, and production app identity belong to the authenticated `data` map; outer metadata must not substitute for or bypass them. |
| authenticated data map -> nested JWS verifiers | Each signed transaction and renewal value remains an independent cryptographic boundary. |
| bounded verifier facts -> NotificationPlug/Intake | Only outer event identity plus independently verified nested facts may create durable wakeup state. |
| concurrent delivery -> database transaction | Provider-event and lineage/environment identities, not process-local checks, must coalesce duplicate work before acknowledgement. |

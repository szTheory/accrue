<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JSON corpus → strict decoder | Checked-in cross-language data must not smuggle unknown fields, duplicate keys, secrets, or a reducer into executable proof. |
| Typed command → production contexts | Test routing selects a production seam, but production code alone decides state transitions. |
| Production persistence → expected-transition matcher | Bounded observed facts may be compared with fixtures; raw evidence, private keys, tokens, and PII must not cross back into the corpus or assertion output. |
| Concurrent/interrupted test control → database | Test-only scheduling hooks may coordinate execution but must not replace database locking, idempotency, or durable resume authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-220-11-01 | Tampering | action JSON and decoder | high | mitigate | Exact family key/type/value validation, duplicate-key rejection, kind equality, action-contract discriminator, and per-family mutation tests reject ambiguous inputs. |
| T-220-11-02 | Spoofing | generic/no-effect executor adapter | high | mitigate | Exhaustive dispatcher plus exact transition matcher and deliberately wrong adapters prove no unrelated seam can satisfy an action. |
| T-220-11-03 | Information Disclosure | durable/cache observations | high | mitigate | Match only bounded IDs/states/counts and reject raw evidence, compact proofs, private JWK members, account tokens, provider payloads, arbitrary metadata, and PII. |
| T-220-11-04 | Tampering | parallel/interrupted execution | high | mitigate | Invoke production idempotency/locking/resume seams under SQL sandbox concurrency and assert exact durable row/state counts after completion. |
| T-220-11-05 | Repudiation | lifecycle and reconnect results | medium | mitigate | Structured expectations include exact result/reason and audit deltas tied to scenario ID, action order, and kind. |
| T-220-11-06 | Elevation of Privilege | fixture executor | high | mitigate | Executor receives test-owned authorization callbacks but cannot mint direct proofs or bypass reconnect admission; boundary tests remain in the acceptance suite. |
| T-220-11-SC | Tampering | package installs | high | mitigate | No package installation is planned; existing lockfiles and dependencies remain unchanged. |
</threat_model>

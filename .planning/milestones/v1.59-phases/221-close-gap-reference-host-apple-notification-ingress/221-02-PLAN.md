<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Internet → Phoenix router | Untrusted body and peer metadata enter the host. |
| Host wrapper → package verifier/intake | Exact bytes and host-owned trust config cross into Accrue's bounded domain path. |
| Runtime environment → verifier/client | Deployment identity, pinned roots, and authorization become live configuration. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-221-04 | Spoofing/Tampering | Apple POST body | high | mitigate | Existing Production verifier authenticates exact captured bytes against pinned roots and application/environment claims before durable verified intake. |
| T-221-05 | Denial of Service | `Plug.Parsers` / NotificationPlug | high | mitigate | Dedicated parser and Plug maximum both equal 262,144 bytes; no browser or Stripe pipeline. |
| T-221-06 | Tampering | Runtime verifier identity | high | mitigate | One production-only immutable config term supplies roots, bundle, app ID, environment, and explicit versions to ingress and admission. |
| T-221-07 | Information Disclosure | Runtime/test evidence | high | mitigate | Runtime helpers never log values; tests use opaque synthetic bytes and assert empty responses/safe durable digests only. |
| T-221-08 | Tampering/Repudiation | Durable acknowledgement | high | mitigate | Router proof requires PostgreSQL-backed intake/wakeup state before 200; notification order never invokes projection. |
</threat_model>

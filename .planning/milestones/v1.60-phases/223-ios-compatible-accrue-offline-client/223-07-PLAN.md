## Trust Boundaries

| Boundary | Description |
|---|---|
| device wall clock → cached authority | Host-supplied `now` can move backward; only a monotonic authenticated observation under the cache lock may influence freshness. |
| authenticated envelope/transaction sidecars → recovered state | Versioned cache and sidecar bytes are untrusted until canonical decoding, path binding, and HMAC authentication succeed. |
| compact reconnect/direct bytes → parser/verifier | Attacker-controlled bytes must pass fixed size/depth admission before decode, recursive scan, Foundation parsing, or signature work. |
| bounded state/reason/action → host display | Failures expose only closed semantic values; reconnect is an action token with accessible text semantics, not additional authority. |

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| GitHub Actions REST → collector | Untrusted repository metadata, names, timestamps, conclusions, URLs, and pagination enter the evidence tool. |
| Fixture/NDJSON → validator/renderer | Local files may be malformed or intentionally crafted to bypass allowlists or inject Markdown. |
| Normalized records → checked-in evidence | Persisted output must not disclose secrets, user data, raw branches, actors, logs, or artifact contents. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-226-01 | Information Disclosure | collector/schema-v1 | high | mitigate | Enforce a record-kind allowlist, reject unknown fields, normalize branches to classes, truncate SHA, and prove forbidden-field rejection with fixtures per D-06. |
| T-226-02 | Tampering | API metadata → Markdown/CLI | high | mitigate | Escape renderer values, validate enums/timestamps/URLs, pass `gh` argv without shell interpolation, and add injection-string negative controls. |
| T-226-03 | Repudiation | cohort and rerun derivation | medium | mitigate | Preserve immutable run IDs/URLs, raw timestamps/conclusions, fingerprint inputs, attempt numbers, and deterministic derivation tests. |
| T-226-04 | Denial of Service | pagination and malformed timestamps | low | accept | Bound the rolling window/sample target, use API pagination deliberately, and fail with deterministic errors rather than retry loops. |
</threat_model>

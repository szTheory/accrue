<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Actions secrets/provider execution → ExUnit formatter | Secret-bearing live test execution emits a durable summary manifest. |
| ExUnit manifest/raw job outcome → proof classifier | Untrusted or malformed counts and conclusions could promote unsupported evidence. |
| Proof record → `GITHUB_STEP_SUMMARY` | External reason/link text crosses into a workflow-command/Markdown rendering surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-226-09 | Information Disclosure | live proof formatter/record | high | mitigate | Serialize only bounded counts/timing/schema fields; exclude messages, names, env data, secret presence, IDs, and payloads; test a secret-like failure fixture. |
| T-226-10 | Tampering | proof-state promotion | high | mitigate | Require the complete D-09 predicate, reject inconsistent counts/manifests, and prove `success`, skip, zero selection, Fake, stale, and SHA mismatch cannot promote. |
| T-226-11 | Tampering | step-summary rendering | high | mitigate | Escape Markdown/control characters, emit via local file append, and fixture-test workflow-command-like input. |
| T-226-12 | Repudiation | latest proved/freshness claim | medium | mitigate | Retain exact SHA/time/cadence/grace, keep stale derived, and never transfer proof to a different SHA. |
</threat_model>

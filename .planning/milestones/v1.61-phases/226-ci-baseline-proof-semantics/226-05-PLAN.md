## Trust Boundaries

| Boundary | Description |
|---|---|
| Actions secrets and job status → workflow scripts | Secret-bearing runtime facts and GitHub expressions enter record-producing commands. |
| Provider/setup records → job summaries/artifacts | Machine facts become human-visible Markdown and retained evidence. |
| Documentation → maintainer action | Incorrect policy/owner/command prose could cause proof promotion or unsafe troubleshooting. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-226-17 | Information Disclosure | workflow summary/artifacts | high | mitigate | Keep secret expressions in env-only provider execution, upload validated allowlisted records only, and statically reject secret interpolation into summary/argv. |
| T-226-18 | Tampering | workflow proof-state wiring | high | mitigate | Bind classification to preflight + manifest + step/job outcomes, always finalize, and retain nonzero selected-run failures. |
| T-226-19 | Elevation of Privilege | workflow permissions/API | high | mitigate | Retain existing read-only permissions and use the already-authenticated read surface; introduce no write token or repository mutation. |
| T-226-20 | Spoofing | docs owner/proof labels | medium | mitigate | Generate assertions from stable codes/states and cross-check docs against executable registries/workflow semantics. |
</threat_model>

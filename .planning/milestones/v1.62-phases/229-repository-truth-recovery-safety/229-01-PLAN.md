<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository refs/filesystem → preservation script | User-owned refs and artifacts enter a command that may create local preservation state. |
| private recovery capsule → committed inventory | Sensitive machine paths and recovery details must be reduced to allowlisted public evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-229-01 | Tampering | `preserve_repository_state.sh` ref ordering | high | mitigate | Freeze all exact `refs/**` name/object/type rows before other ref work, retain original mappings privately, use reversibly encoded collision-safe preservation names, verify bundle membership and every object, and stop before any later observation on failure. |
| T-229-02 | Information Disclosure | inventory schema and renderer | high | mitigate | Reject non-allowlisted keys, absolute/traversing paths, environment values, actors, raw logs/payloads, and external bundle locations before writing JSON or Markdown. |
| T-229-03 | Elevation of Privilege | shell arguments and git object expressions | high | mitigate | Strict option parsing, quoted argv, full-object validation, fixed preservation namespace, and no evaluated shell input. |
| T-229-04 | Repudiation | recovery proof | medium | mitigate | Record every original ref mapping privately plus encoded preservation name, object ID, bundle digest/membership result, observation time, and restore template; record typed non-dereferenced artifact evidence and pre/post invariants. |
</threat_model>

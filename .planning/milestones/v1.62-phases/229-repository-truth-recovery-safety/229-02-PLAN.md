## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-229-05 | Tampering | GitHub command registry | high | mitigate | Fixed read-only subcommands, injected adapter invocation audit, explicit repository argv, and rejection of all unregistered operations. |
| T-229-06 | Spoofing | run/SHA attribution | high | mitigate | Validate full SHA, require exact repository on each request, echo both in every result, and reject no-match/ambiguous results. |
| T-229-07 | Denial of Service | watch polling | high | mitigate | Positive poll interval, absolute timeout, safe maxima, bounded response size, and deterministic timeout exit. |
| T-229-08 | Information Disclosure | failure summaries | medium | mitigate | Allowlist job/step fields and bounded diagnostics; omit actors, environment, raw logs, payloads, and tokens. |
</threat_model>

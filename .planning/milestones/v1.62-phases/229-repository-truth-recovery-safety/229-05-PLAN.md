| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|

| T-229-G05-02 | Elevation of Privilege | ref restoration metadata | high | mitigate | Store and execute argv arrays without a shell; fixtures include valid metacharacter-bearing refs. |
| T-229-G05-03 | Information Disclosure | private scratch inventories | high | mitigate | Trap and remove only the exact command-created scratch directory on every exit. |
| T-229-G05-04 | Repudiation | public recovery record | medium | mitigate | Derive private/public digests from one retained shell value and validate the final published triplet. |
</threat_model>

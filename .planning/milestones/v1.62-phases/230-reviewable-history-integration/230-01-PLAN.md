## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argv → git plumbing | Operator-supplied ref names, phase values, and paths reach `git` and the shell |
| Repository working tree → out-of-repo capsule | Object data and file digests leave the repository into a filesystem location outside version control |
| Repository state → committed evidence artifact | Facts about refs and objects become a public, committed JSON file |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

<threat_model>
ASVS level: **1**. Blocking severity: **high**.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Abandoned local history → ledger classification | Content from an abandoned execution line determines what is recorded as superseded |
| Commit subjects → rendered public Markdown | Untrusted commit message text is rendered into a committed public artifact |
| Remote branch state → `published_elsewhere` | A public remote ref name is recorded in committed evidence |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-230-04-01 | Repudiation | An excluded commit with no recorded disposition | high | mitigate | `--require-excluded-ledger` asserts two-sided exact multiset equality against the live recomputed excluded set, with a literal integer count. |
| T-230-04-02 | Spoofing | A patch-id coincidence presented as supersession | high | mitigate | Supersession requires tree-level file-existence evidence plus the requirement-level `BASE-01`/`BASE-02` completion citation; patch-id data is recorded as recomputed integer occurrence counts in fields distinct from `supersession_evidence`. |
| T-230-04-03 | Tampering | Commit subject text injecting Markdown or plan structure into the rendered artifact | medium | mitigate | Every rendered cell passes through the inherited `escape()` helper, which neutralises pipes, backticks, angle brackets, and collapses newlines. |
| T-230-04-04 | Information disclosure | Commit subjects or branch names carrying adopter identifiers into public evidence | high | mitigate | Allow-listed field sets; subjects escaped and single-lined; adopter-named refs recorded only by names already public on `origin`, adding no new exposure; no absolute paths, no `$HOME`, no actor names. |
| T-230-04-05 | Tampering | A row silently dropped to shorten the ledger | high | mitigate | Exact multiset equality fails on any missing row; `exactMap` fails on any duplicate key; the count is a literal integer. |
| T-230-04-06 | Elevation of privilege | The ledger collector mutating repository state | high | mitigate | Collection is read-only plumbing (`rev-list`, `patch-id`, `cat-file`, `show`, `diff --name-only`); no `update-ref`, `fetch`, `push`, `cherry-pick`, or `commit` on refs. |
| T-230-04-07 | Denial of service | `git patch-id` over hundreds of commits | low | accept | The excluded set is bounded by the ~80-commit abandoned line; the inherited `run()` wrapper bounds timeout and buffer. |
| T-230-04-SC | Tampering | npm/pip/cargo installs | high | accept | No package-manager install occurs in this plan. |
</threat_model>

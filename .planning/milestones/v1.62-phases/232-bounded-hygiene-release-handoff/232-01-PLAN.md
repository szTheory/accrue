<assumption_delta_decision>
**Noun now primary:** `isMainModule(import.meta.url)` from `scripts/ci/main_module.mjs` — the single,
shared, realpath-resolved module-boundary guard.

**Decision:** `promote`.

**Rationale:** the two inline idioms are not alternative spellings of a working check; both are
empirically broken under a space-containing checkout path (re-verified in 232-RESEARCH.md DRIFT-3 on
the current Node). Adding the shared helper *alongside* the inline idioms is what would let a 21st
file mint a third variant. The inline idioms are therefore demoted to zero occurrences across
`scripts/ci/*.mjs` by plan 232-02, not kept as a permitted alternative.

**Invariant test that goes red on reintroduction:** `scripts/ci/verify_ci_script_contract.mjs`
(plan 232-03, D-32) already is exactly that test — it asserts every `scripts/ci/*.mjs` either imports
`isMainModule` or is a `*.test.mjs` file. No second invariant test is needed or wanted.
</assumption_delta_decision>

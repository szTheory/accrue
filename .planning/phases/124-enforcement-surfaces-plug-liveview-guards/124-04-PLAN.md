Ship the LiveView enforcement surface for ENT-07: the conditionally-compiled `Accrue.Live.Entitlements` `on_mount` guard. <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LiveView socket → on_mount chain | The socket assigns are populated by upstream on_mount hooks; this guard must run AFTER the host's auth hook or it denies authenticated users (assign-ordering). |
| deny redirect target → browser | The redirect path is host-declared config; must live outside the gated live_session to avoid loops. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-124-11 | Elevation of Privilege | entitlement on_mount running before auth populates the scope → spurious deny / or fail-open if mis-ordered | mitigate | Moduledoc documents LOUDLY that the host's auth `on_mount` MUST precede this guard (D-20); the guard gates entitlement only and denies when billable is nil (fail-closed). Tested: unentitled/nil-billable → `{:halt, …}` Task 2(3). |
| T-124-12 | Information Disclosure | flash/redirect leaking which tier gates what | mitigate | Generic opaque flash ("You don't have access to this page."), never names the feature/plan (D-10). Tested: opacity assertion Task 2(4). |
| T-124-13 | Denial of Service | redirect loop when deny_path is inside the gated live_session | mitigate | Moduledoc documents the deny destination must live outside the gated live_session (D-13/Pitfall 6); no redirect default that points back into the gate. |
| T-124-14 | Tampering | LiveView socket runtime leaking into always-compiled core | mitigate | All `Phoenix.LiveView`/`Phoenix.Component` refs confined inside the `Code.ensure_loaded?` block of this single file under `lib/accrue/live/`; the Plan 06 merge gate (excluding `/accrue/live/`) enforces this invariant. |

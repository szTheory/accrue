<objective>
Make the Phase-128 dunning campaign lifecycle observable by emitting four lifecycle events — `dunning.campaign_started`, `dunning.step_sent`, `dunning.recovered`, `dunning.exhausted` — as BOTH a dotted `accrue_events` ledger entry AND an `[:accrue, :ops, :dunning_*]` telemetry event, and registering every telemetry event across the enforced drift-gate triad (inventory + metrics + guide).

Purpose: DUN-08 observability contract. The ledger entries are the audit trail and the substrate the recovered-vs-lost counter (Plan 02) folds over; the telemetry family is live metrics for operators. This deviates from DUN-08's literal `[:accrue, :dunning, *]` spelling on purpose (D-01): the shipped+enforced idiom is `[:accrue, :ops, :dunning_*]`, and a parallel `:dunning` root would fork the contract and bypass the drift gate.

Output: 4 ledger emit sites + 4 telemetry emit sites in `lib/`, the four-surface drift-gate registration (inventory list, metrics counters, guide catalog+runbook), and extended unit tests asserting each emission.
</objective>

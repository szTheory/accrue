<objective>
Add a read-only dunning-state `ax-card` to the admin subscription detail LiveView so an operator can see exactly where a customer is in their dunning journey: campaign-active state, started-at, and the next scheduled action — every string routed through the `AccrueAdmin.Copy` SSOT.

Purpose: DUN-07 / SC#2. Output: the read-only `ax-card` markup + helpers (`next_action_summary/1`, `dunning_badge_tone/1`), new dunning Copy strings (defs + delegates), and LiveView render tests proving presence, the read-only contract, and copy routing.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-129-11 | Tampering / EoP | admin dunning panel | mitigate | The panel is STRICTLY read-only (D-12): no `phx-click`/`phx-submit`/`<button>`/`<form>`. No state-mutating action exists, so an operator cannot tamper with campaign state from this surface. Enforced by the render test `refute has_element?(... button)` and the grep gate. |
| T-129-12 | Information Disclosure / cross-tenant | panel data source | mitigate | The panel reads ONLY `@subscription` already loaded via `Subscriptions.detail/2` under `current_owner_scope` (returns :not_found cross-scope). Add NO new query or data path that bypasses scoping. No deep Chimeway/Stripe introspection (milestone Out-of-Scope). |
| T-129-13 | Information Disclosure | rendered fields | mitigate | The panel renders only safe operator fields: campaign-active state, started-at timestamp, next-step key, schedule duration. NO Stripe secret, card data, or PII is rendered or logged (V7). Operator terms ("dunning campaign", "step") are acceptable on the operator surface and route through Copy. |
| T-129-14 | Availability | next_step/3 resolution failure | mitigate | If `next_step/3` cannot resolve (config steps unavailable), the helper returns `Copy.dunning_next_action_unavailable()` instead of crashing the LiveView — the rest of the panel still renders from already-loaded state. |
| T-129-SC | Tampering | npm/pip/cargo installs | n/a | No package installs (zero external packages). |

<objective>
Establish the foundational contract for DUN-03: the `Accrue.Dunning.Engine` behaviour (the
swappable seam, D-01) and the `dunning: [engine: Module]` config key + `Config.dunning_engine/0`
accessor (D-03). This plan defines the interface that Plan 03 (Engine.Oban) and Plan 04 (Chimeway
adapter) implement against, and the config dispatch point Plan 03 wires `default_handler.ex` through.

Purpose: Interface-first ordering — downstream implementers receive the contract in the plan, not
via codebase scavenging.
Output: One new behaviour module + a config schema/accessor extension.

NOTE: The default value `Accrue.Dunning.Engine.Oban` is referenced before that module exists
(Plan 03 creates it). This is intentional and safe: NimbleOptions stores the atom literally and
`Config.dunning_engine/0` returns the atom without loading the module. The atom default does not
require the module to be compiled at the time the config schema is defined.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host config → Config schema | The `:engine` value is host-supplied at boot; NimbleOptions validates it is an atom. The behaviour contract is enforced by `@behaviour` on each adapter (compile-time). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-131-02 | Tampering | host sets `:engine` to a module not implementing the behaviour | accept | NimbleOptions `:atom` accepts any atom; a non-conforming module raises `UndefinedFunctionError` at first dispatch (loud, host-owned misconfig). The behaviour `@behaviour` attribute on first-party adapters is the supported path. Documented in the key `doc:`. |
| T-131-03 | Denial of Service | engine atom default references not-yet-compiled module | mitigate | Accessor returns the atom only (no `Code.ensure_loaded?`/no module load); the module is resolved at dispatch time in `default_handler.ex` where Engine.Oban is always present. |
| T-131-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan. The optional `:chimeway` dep is added in Plan 04 and gated there. |
</threat_model>

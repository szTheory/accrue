## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | DaisyUI `base-100` | Background, main surfaces |
| Secondary (30%) | DaisyUI `base-200`/`base-300` | Cards, sidebar, nav, empty states |
| Accent (10%) | DaisyUI `primary` | Primary action buttons, active links |
| Destructive | DaisyUI `error` | Destructive actions, hard errors |

Accent reserved for: Primary Call-to-Action (CTA) buttons (e.g., "Upgrade Plan"), active navigation indicators.

---

## Visual Hierarchy

- **Focal Point:** The primary CTA ("Upgrade Plan") within the empty/error state container, visually anchored using the Accent color on an otherwise neutral (Secondary) background.

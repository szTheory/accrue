  <files>accrue_admin/assets/js/hooks/command_palette.js, accrue_admin/assets/js/app.js</files>
  <action>
    Implement the Vanilla JS Hook `CommandPalette` to handle zero-latency keyboard navigation.

    In `command_palette.js`:
    - Listen globally for `CMD+K` (or `CTRL+K`). Call `preventDefault()` to block the browser search, and push an event to the LiveComponent to toggle `@is_open`.
    - Trap focus in the search input when opened.
    - Listen for `keydown` (ArrowDown, ArrowUp). Prevent default scrolling and visually update an `.active` CSS class traversing through the rendered `<li>` result items.
    - Listen for `Enter`. Read the `data-path` of the `.active` item and use `window.liveSocket.pushHistoryPatch(path, "push", this.el)` to instantly navigate.
    - Provide an `updated()` callback to reset the active index to 0 whenever LiveView patches the DOM (e.g., new results arrive).

    In `app.js`:
    - Import the hook.
    - Initialize the LiveSocket passing `hooks: { CommandPalette }` in the options.

    Ensure `global_search.ex` attaches this hook via `phx-hook="CommandPalette"` to its main wrapper element.
  </action>

      - Generate a new ID using `@invoice_item_prefix`.
      - Build an `invoice_item` map (atomized params + id + object: "invoice_item").
      - If `invoice` ID is present in params:
        - Find the invoice in `state.invoices`.
        - Add the new item to its `lines.data` list.
        - Update invoice totals (subtotal, total) by adding `amount`.
        - Update the invoice in `state.invoices`.
      - Store the item in `state.invoice_items`.
      - Return `{:ok, item}`.
    - Implement `handle_call({:invoice_item_delete, id, params, opts}, _from, state)`:
      - Find the item in `state.invoice_items`.
      - If found:
        - If the item was attached to an invoice (check `invoice` field):
          - Find the invoice in `state.invoices`.
          - Remove the item from `lines.data`.
          - Update invoice totals by subtracting `amount`.
          - Update the invoice in `state.invoices`.
        - Remove item from `state.invoice_items`.
        - Return `{:ok, %{id: id, object: "invoice_item", deleted: true}}`.
      - If not found, return `{:error, resource_missing(id)}`.
  </action>

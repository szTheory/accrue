  <name>Task 1: Implement InvoiceActions Logic</name>
  <files>accrue/lib/accrue/billing/invoice_actions.ex</files>
  <action>
    - Add `add_invoice_item/3`:
      - Validate `invoice.status == :draft`.
      - Prepare params: `%{customer: invoice.customer.processor_id, invoice: invoice.processor_id} |> Map.merge(attrs)`.
      - Start `Repo.transact`:
        - `Processor.invoice_item_create(params, opts)`.
        - `Processor.retrieve_invoice(invoice.processor_id, opts)`.
        - `InvoiceProjection.decompose(stripe_inv)`.
        - `update_invoice_row(invoice, attrs)`.
        - `sync_items(updated, item_attrs_list)` (see below).
        - `record_event("invoice.item_added", updated)`.
    - Add `remove_invoice_item/3`:
      - Validate `invoice.status == :draft`.
      - Start `Repo.transact`:
        - `Processor.invoice_item_delete(item.processor_id, opts)`.
        - `Processor.retrieve_invoice(invoice.processor_id, opts)`.
        - `InvoiceProjection.decompose(stripe_inv)`.
        - `update_invoice_row(invoice, attrs)`.
        - `sync_items(updated, item_attrs_list)`.
        - `record_event("invoice.item_removed", updated)`.
    - Implement `sync_items(invoice, item_attrs_list)`:
      - Get `new_stripe_ids` from `item_attrs_list`.
      - Delete all `InvoiceItem` rows for this `invoice_id` where `stripe_id` is NOT in `new_stripe_ids`.
      - Call existing `upsert_items(invoice, item_attrs_list)`.
    - Add bang variants `add_invoice_item!/3` and `remove_invoice_item!/3`.
  </action>
  <verify>
    <automated>mix compile</automated>
  </verify>

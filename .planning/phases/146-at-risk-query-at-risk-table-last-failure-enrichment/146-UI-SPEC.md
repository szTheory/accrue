## Layout Contract

### Placement in RecoveryLive

The `.ax-page` grid renders four children in vertical order after this phase:

1. `.ax-page-header` — breadcrumbs + eyebrow + h2 + WindowSelector (unchanged)
2. `.ax-kpi-grid` — 2 KpiCards (unchanged)
3. `FunnelChart` — `<article class="ax-card ax-funnel-chart">` (unchanged)
4. `AtRiskTable` — NEW: `<section class="ax-card ax-at-risk-table">` (added by this phase)

Gap between all children is `var(--ax-space-xl)` (32px) via `.ax-page { gap: var(--ax-space-xl) }`.

### Table structure (desktop: ≥ 1024px)

```
<section class="ax-card ax-at-risk-table">
  <header class="ax-at-risk-header">
    <p class="ax-label">At-Risk Subscriptions</p>
    <p class="ax-body ax-muted">{N} active dunning campaigns in this window</p>
  </header>

  <!-- Non-empty: show table -->
  <table class="ax-at-risk-grid">
    <thead>
      <tr>
        <th class="ax-label">Customer</th>
        <th class="ax-label">Days in Campaign</th>
        <th class="ax-label">Current Step</th>
        <th class="ax-label">Next-Step ETA</th>
        <th class="ax-label">Last Failure Reason</th>
      </tr>
    </thead>
    <tbody>
      <tr :for={row <- @rows}>
        <td><a href={drill_down_href(@base_path, row)} class="ax-link">{customer_label}</a></td>
        <td class="ax-body">{N} days</td>
        <td class="ax-body">Step {N}</td>
        <td class="ax-body">{formatted ETA or "—"}</td>
        <td class="ax-body ax-muted">{failure_reason or "—"}</td>
      </tr>
    </tbody>
  </table>

  <!-- Empty state: no active dunning campaigns -->
  <div class="ax-empty-state" data-role="empty-state">
    <p class="ax-heading">No active dunning campaigns</p>
    <p class="ax-body">All subscriptions in this window have recovered or exhausted their campaign.</p>
  </div>
</section>
```

### Row-click affordance (stub for Phase 147)

- The Customer cell renders an `<a class="ax-link">` tag.
- `href` is constructed as `{base_path}/analytics/recovery/subscriptions/{subscription_id}`.
- Phase 147 defines this route — until then the href resolves to a 404 (acceptable; not a broken `#`).
- No `phx-click` needed: standard anchor navigation.
- No row-level click on `<tr>` — only the Customer cell link is interactive.

## Interaction Contract

### Static assign pattern

- `RecoveryLive.handle_params/3` calls `Dunning.at_risk_subscriptions(since: since, until: until)` and assigns result to `@at_risk`.
- Component receives `rows={@at_risk}` — a plain list, never a LiveView stream.
- On window change (user clicks 7d / 30d / 90d), `handle_params/3` re-runs and re-assigns `@at_risk`. Table re-renders as static diff.

### Empty state trigger

- `rows` is an empty list `[]` → render empty state div, hide table.
- `rows` is non-empty → render table, hide empty state.
- No loading state needed — mount is synchronous; if the query is slow the page load is slow (acceptable for an analytics dashboard).

### Keyboard / accessibility

- `<th scope="col">` on every column header.
- Customer `<a class="ax-link">` is the only focusable element per row.
- No `tabindex` on `<tr>` — rows are not keyboard-navigable.
- `<section>` landmark wraps the component; screen readers can navigate to it by landmark.
- Empty state uses `<p class="ax-heading">` + `<p class="ax-body">` — plain text, no aria roles needed.

### Responsive behaviour

- At < 1024px: the table is displayed as-is (no card-list fallback needed; this is a read-only analytics table, not the full DataTable component).
- Horizontal scroll on the `<section>` or `<table>` via `overflow-x: auto` on `.ax-at-risk-table` (new CSS rule required — see CSS notes below).

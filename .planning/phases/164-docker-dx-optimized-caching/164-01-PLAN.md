<task type="auto">
  <name>Task 2: Create docker-compose.yml</name>
  <files>examples/accrue_host/docker-compose.yml</files>
  <action>Create a Docker Compose orchestrator for local development.
- Define a `db` service using `postgres:15-alpine`. Map port 5432:5432, use `POSTGRES_USER=postgres`, `POSTGRES_PASSWORD=postgres`, `POSTGRES_DB=accrue_host_dev`. Keep DB data in a named volume (`pgdata:/var/lib/postgresql/data`).
- Define a `web` service. Set `build.context` to `../..` (the monorepo root) and `build.dockerfile` to `examples/accrue_host/Dockerfile.dev`.
- In `web`, map port 4000:4000.
- Pass environment variables to `web`: `PGHOST=db`.
- Crucial Volume Masking (for EVD-04): Mount `../..:/workspace` to provide access to the monorepo path dependencies. Then, mask the build directories with named volumes so host-compiled binaries don't conflict with container-compiled ones:
  - `mix_deps:/workspace/examples/accrue_host/deps`
  - `mix_build:/workspace/examples/accrue_host/_build`
  - `assets_node_modules:/workspace/examples/accrue_host/assets/node_modules`
- Declare the named volumes (`pgdata`, `mix_deps`, `mix_build`, `assets_node_modules`) at the bottom of the file.</action>
  <verify>
    <automated>grep -v '^#' examples/accrue_host/docker-compose.yml | grep -c "assets_node_modules" | grep -q "[1-9]"</automated>
  </verify>
  <done>docker-compose.yml is created linking the database and web container, with proper volume masking.</done>

<objective>
Wire JS.transition for the 3 Elixir component surfaces that mount/remove from the DOM:
detail_drawer, flash_group articles, and the More ▾ menu. Also add phx-mounted content
fade-in to data_table. These surfaces require Phoenix.LiveView.JS.show/hide with transition
tuples because they use :if-gated DOM mount/remove — CSS alone cannot animate them.

phx-mounted / phx-remove attrs on the `:if`-gated elements, with JS.show/JS.hide calls
using transition tuple class names that resolve to the CSS in app.css.

- app.css: ax-drawer-* and ax-flash-* CSS transition class tuples (6 classes each direction)
- detail_drawer.ex: phx-mounted JS.show + phx-remove JS.hide on the :if-gated section

  .ax-tab-more-open .ax-tab-more-menu CSS rule activates

  from Plan 02

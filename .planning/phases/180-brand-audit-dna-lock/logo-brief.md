# Accrue Logo Design Brief
*Binding — Phase 180 checkpoint. Phase 181 pre-gate lints enforce these constraints programmatically.*

## Hard Logo Constraints
*(4 hard constraints — binding on every Phase 181+ candidate; enforced as pre-gate lints)*

1. **No rectangular background/container shape** behind the logomark — marks breathe / break boundaries
2. **Logotype optically close** to the mark — not visually separated
3. **Main lockup carries no subtitle** — a separate with-subtitle variant ships
4. **Fully-integrated custom typemark options required** — motif/flourish worked into letterforms, not icon-left-of-text

→ `BRAND-AUDIT.md §8`, `BRAND-DNA.md §Logo Constraints`

## Design Posture
"Well-made dev tooling," not fintech.
State/lifecycle imagery (accumulation, timelines, layered records) — never finance clichés (coins, cards, carts).
Exemplar family: Prisma, Vercel (minimal, geometric, high-precision) — not Supabase (vibrant, velocity-forward).
→ `BRAND-AUDIT.md §8`, `BRAND-AUDIT.md §9`

## Derived Suite (Phase 183 target)
- Primary lockup: mark + close-set logotype, no subtitle
- Integrated typemark: motif/flourish worked into letterforms
- Icon-only mark
- Monochrome positive / negative
- Dark-bg / light-bg versions
- Favicon (SVG + .ico + minimal PNG set)
- Social card (SVG + PNG)
- With-subtitle variant (separate from primary lockup)
- Clearspace / minimum-size spec sheet

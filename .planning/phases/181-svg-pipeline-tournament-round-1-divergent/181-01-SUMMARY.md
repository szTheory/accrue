## Decisions Made

1. **Direct node_modules path for geist TTF** — `require.resolve()` fails because the `geist` package.json `exports` map only declares JS entry points, not font file paths. Plan said to use `require.resolve()` as primary with path.join as fallback, but path.join is the only working approach. Used `path.join(__dirname, 'node_modules/geist/dist/fonts/geist-sans/Geist-Regular.ttf')` as primary.

2. **Actual font filename is `Geist-Regular.ttf`** — RESEARCH.md specified `GeistSans-Regular.ttf` but the installed `geist@1.7.2` package ships `Geist-Regular.ttf`. Code tries the research-specified name first, then falls back to the actual name.

3. **wawoff2 WASM memory safety** — `wawoff2.decompress()` returns a `Uint8Array` whose `.buffer` is backed by the WASM module's internal `SharedArrayBuffer`. `opentype.parse()` requires a plain isolated `ArrayBuffer`. Fix: `const ab = new ArrayBuffer(decompressed.length); new Uint8Array(ab).set(decompressed); opentype.parse(ab)`.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] geist exports map blocks require.resolve() for TTF paths**
- **Found during:** Task 2 (geist-spine.mjs implementation)
- **Issue:** The plan specified `require.resolve('geist/dist/fonts/geist-sans/GeistSans-Regular.ttf')` but the geist package.json `exports` field only exposes JS entry points. Node.js throws `Package subpath './dist/fonts/geist-sans/...' is not defined by "exports"`.

- **Files modified:** harness/geist-spine.mjs

**2. [Rule 1 - Bug] wawoff2 WASM buffer requires explicit ArrayBuffer copy**
- **Found during:** Task 2 (wawoff2 fallback testing)
- **Issue:** `opentype.parse(result.buffer)` threw `Unsupported OpenType signature` because `result.buffer` (from `Uint8Array`) is a reference to WASM module's memory region, not an isolated ArrayBuffer. opentype.js cannot safely parse from shared memory.
- **Fix:** Copy into a fresh ArrayBuffer: `const ab = new ArrayBuffer(decompressed.length); new Uint8Array(ab).set(decompressed); opentype.parse(ab)`.
- **Files modified:** harness/geist-spine.mjs
- **Verification:** Manual test confirmed wawoff2 fallback parses successfully (`Parse OK, unitsPerEm: 1000`).
- **Committed in:** aff992b9 (Task 2 commit)

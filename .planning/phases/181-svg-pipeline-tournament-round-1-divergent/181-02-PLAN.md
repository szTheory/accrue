From RESEARCH.md Pattern 4 (pngjs pixel heuristics — for 16px lint):
- Contrast ratio: minimum 3:1 (WCAG AA-large for icons)
- Edge-density ratio (16px vs 32px): fail if < 0.35
- luminance formula: WCAG 2.0 normative (s <= 0.03928 ? s / 12.92 : pow((s+0.055)/1.055, 2.4))

From RESEARCH.md Pattern 5 (pre-gate lint algorithms):
- lintNoRectBackground: any <rect> w*h >= 0.8 * viewBox area → fail
- lintNoSubtitle: more than 1 <text> element → fail (heuristic: logotype spelled out is 1 text group)
- lintMonochromeDeriv: hex color with HSV saturation > 0.15 → fail
- lintLockupGapRatio: gap = logotype.xMin − mark.xMax; spec: 0.08–0.35 × capHeight; Direction D skips this check

From RESEARCH.md Pitfall 5 (gap-ratio false-failures):
- Direction D typemarks have NO spatial gap (mark IS the letterform)
- lint.mjs reads `candidate.skipGapRatio === true` and logs a note instead of failing

From RESEARCH.md Pitfall 6 (@xmldom/xmldom namespaces):
- Use 'image/svg+xml' MIME type in DOMParser.parseFromString()
- Strip xmlns:xlink from generated SVGs since opentype.js output doesn't need them

From PATTERNS.md (assemble-lockup.mjs section):
- gapRatio default: 0.15 (gap = capHeight * gapRatio)
- `{ markIsTypemark: true }` flag skips gap enforcement for Direction D — produces single unified path group
- Assembler exports: assembleLockup(markPathD, glyphs, config) → SVG string
- config shape: { markWidth, capHeight, gapRatio = 0.15, fontSize = 1000, viewboxH, markIsTypemark = false }

From PATTERNS.md (lint.mjs NDJSON output shape):
- One NDJSON line per lint check per candidate
- Schema: { candidateId, lint, pass, reason }

    **Direction C: `dirs/c-arcs.mjs`** — layered arcs / state transition mark.

    Motif concept: concentric or offset partial arcs — 2–4 arcs layered at different radii or angular offsets, reading as state-machine transitions, progress rings, or lifecycle stages. Fits brand metaphor: state transitions, layered records, accumulation.

    Knobs (3–4): `arcCount` (int 2–4), `sweep` (float 60–300 degrees — angular sweep of each arc), `radiiSpread` (float 0.2–0.5 — gap between arc radii as fraction of outerRadius), `strokeWidth` (float 1.5–4.0 — arc stroke width in coordinate units), `offset` (float 0–45 degrees — rotational offset between successive arcs).

    Geometry: each arc is drawn as a stroked open path using SVG arc commands `M {x1},{y1} A {rx},{ry} 0 {largeArc} {sweep} {x2},{y2}`. Arcs are concentric around a center point; outer arc has radius ≈ 30 units; successive arcs are smaller by `radiiSpread` each. Arcs are `stroke="#111418" fill="none"` — this is mark geometry (monochrome, uses Ink). The mark bounding box is `2 * outerRadius × 2 * outerRadius`.

    Arc path construction helpers: given center (cx, cy), radius r, startAngle, endAngle (degrees), returns M/A path string. Use `Math.cos(deg * Math.PI/180)` for coordinates.

    CONFIGS (5–6 entries):
    ```
    C1: { id: 'C1', arcCount: 3, sweep: 200, radiiSpread: 0.25, strokeWidth: 2.0, offset: 30 }
    C2: { id: 'C2', arcCount: 2, sweep: 270, radiiSpread: 0.30, strokeWidth: 3.0, offset: 0 }
    C3: { id: 'C3', arcCount: 4, sweep: 150, radiiSpread: 0.20, strokeWidth: 1.5, offset: 45 }
    C4: { id: 'C4', arcCount: 3, sweep: 240, radiiSpread: 0.35, strokeWidth: 2.5, offset: 20 }
    C5: { id: 'C5', arcCount: 2, sweep: 300, radiiSpread: 0.40, strokeWidth: 2.0, offset: 15 }
    ```

    Each config has a `rationale` string.

    Important: arc-based marks use `stroke` not `fill` for the mark geometry. This creates a challenge for the `lintMonochromeDeriv` check since arcs are stroked. The `generate()` output should include stroke colors in the `d` attribute wrapper — OR the generator returns a pair `{ markPathD, markWidth, markHeight, markSvgAttrs }` where `markSvgAttrs = 'stroke="#111418" fill="none" stroke-width="{strokeWidth}"'`.

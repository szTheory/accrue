    - `TARGET_GALLERY_SIZE = { min: 12, max: 16 }`

    main() logic:

    **Step 1 — Load font:**
    `const font = await loadGeistFont()` (log `[generate] Loading Geist font…`). Compute `capHeight = getCapHeight(font)`. Extract "accrue" glyphs: `const accrueGlyphs = extractGlyphs(font, 'accrue', 1000)`. Assert `accrueGlyphs.length === 6` — exit(1) with message if not (handles ligature edge case A4 from RESEARCH.md).

    **Step 2 — Create output directories:**
    `fs.mkdirSync(CANDIDATES_DIR, { recursive: true })`, same for REJECTED_DIR and SCREENSHOTS_DIR.

    **Step 3 — Generate all raw candidates:**
    For each direction (A, B, C): loop CONFIGS; call `generate(config)` to get `{ markPathD, markGroupSvg, markWidth, markHeight }`; call `assembleLockup(markPathD, accrueGlyphs, { markWidth, capHeight, gapRatio: 0.15, fontSize: 1000, viewboxH: capHeight * 1.4 })` to get full lockup SVG; build candidate object `{ id, direction, config, markPathD, lockupSvg: assembled.svg, markBbox: computed, logotypeBbox: computed, capHeight, skipGapRatio: false, rationale: config.rationale }`. In SMOKE mode: only take CONFIGS[0] per direction.

    For direction D: loop D CONFIGS; call `generate(config, font)` to get `{ fullSvg, markIsTypemark: true, markWidth, markHeight, skipGapRatio: true }`; build candidate `{ id, direction: 'D', config, lockupSvg: fullSvg, markIsTypemark: true, skipGapRatio: true, rationale: config.rationale }`.

    markBbox and logotypeBbox for A/B/C: use `computeMarkBbox(markPathD)` from assemble-lockup.mjs; logotype bbox starts at `markWidth + capHeight * 0.15` (the default gap).

    **Step 4 — Run lints:**
    For each raw candidate: call `lintCandidate(candidate, { lintLogPath: path.join(PHASE_DIR, 'lint-results.ndjson') })`. If `result.pass === false`: move SVG to rejected/ with reason sidecar (log `[generate] Culled {id}: ${result.failures.join(', ')}`); `continue`. If pass: push to `passing` array.

    **Step 5 — Per-direction floor check:**
    Count passing candidates per direction. If any direction has < `MIN_PER_DIRECTION` (3) AND we are NOT in SMOKE mode: for that direction only, generate additional configs by mutating knobs (e.g., `amplitude *= 1.2`, try CONFIGS[0] variant); run lints on new candidates; add passing ones to `passing` array (log `[generate] Direction {X} below floor — running targeted regeneration`). Cap at 2 retry attempts per direction (not unbounded per D-05). If still below floor after retry, log a warning `[generate] WARN: Direction {X} has only {n} candidates after regeneration` but do not abort.

    **Step 6 — Cull to target gallery size (12–16):**
    If `passing.length > 16`: apply a simple quality-based cull. For now, truncate to the first 16 in insertion order (a more sophisticated score-based cull can be added in Plan 06 after self-review scores are available). Log culled entries.

    **Step 7 — Write candidates:**
    For each passing candidate: `fs.writeFileSync(path.join(CANDIDATES_DIR, '${candidate.id}.svg'), candidate.lockupSvg)`. Also write a `${candidate.id}.json` sidecar with `{ id, direction, config, rationale, skipGapRatio }` (used by render-matrix.mjs and build-gallery.mjs).

    **Step 8 — Write metadata index:**
    `fs.writeFileSync(path.join(CANDIDATES_DIR, 'index.json'), JSON.stringify(candidates.map(c => ({ id: c.id, direction: c.direction, rationale: c.rationale })), null, 2))`.

    Summary log line: `console.log('[generate] Done: ${passed} passed / ${culled} culled → ${passing.length} gallery candidates in ${CANDIDATES_DIR}')`. Exit 0.

    Smoke mode should complete in <10 seconds (4 candidates, minimal lint work, no screenshots — screenshots happen in Plan 06).

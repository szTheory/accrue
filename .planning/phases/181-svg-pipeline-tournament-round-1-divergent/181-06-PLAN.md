<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SVG inlined into gallery HTML | Self-generated SVG embedded into HTML; not user input; low XSS risk in file:// context |
| navigator.clipboard.writeText() | User-initiated clipboard write on file:// (potentially trustworthy origin); falls back to visible pre |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-181-13 | Tampering | Inlined SVG in gallery HTML containing active content (script/event handlers) | mitigate | Generated SVGs are from local generators only (no external SVG fetch); generators produce path elements only (no `<script>` or `on*` handlers in generated paths); DOMParser lint validates SVG structure |
| T-181-14 | Information Disclosure | file:// gallery accessing other local files | accept | Gallery only references relative paths (screenshots/ dir); no absolute file:// paths to sensitive locations; verdict JS only writes to clipboard |
| T-181-15 | Tampering | Playwright tmp HTML files not cleaned up | mitigate | render-matrix.mjs deletes _tmp_{tileId}.html after screenshot via fs.unlinkSync() in try/finally |
</threat_model>

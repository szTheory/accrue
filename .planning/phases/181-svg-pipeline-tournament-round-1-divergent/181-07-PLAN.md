    - `avatar-crop-integrity`: Does the mark read clearly in a tight 96×96 circle? Score 2 if the mark is distinct and doesn't look empty; score 1 if it reads as generic; score 3 if it's immediately distinctive.

Score 3 if it strongly evokes the brand DNA vocabulary; score 2 if it's consistent and professional; score 1 if it could be any tech product; score 0 if it evokes finance clichés.

    Step 1 — Write .planning/phases/182-tournament-convergent-refinement/harness/generate-r2.mjs.

    This is the Round 2 orchestrator. It imports harness primitives from the 181 harness and R2_CONFIGS + generate from b-step-r2.mjs, then runs the full candidate-generation loop. The 181 harness's generate.mjs main() should NOT be called — import only the primitive functions.

    Structure (ESM, no dependencies other than 181 harness and b-step-r2.mjs):

    ```
    import path from "path";
    import { fileURLToPath } from "url";
    import fs from "fs";

    const __dirname = path.dirname(fileURLToPath(import.meta.url));
    // 182 phase dir is two levels up from harness/dirs/ → harness/ → 182 root
    const PHASE_DIR = path.resolve(__dirname, "..");   // 182 phase dir
    const HARNESS_DIR = path.resolve(__dirname,
      "../../181-svg-pipeline-tournament-round-1-divergent/harness");

    const CANDIDATES_DIR  = path.join(PHASE_DIR, "candidates");
    const REJECTED_DIR    = path.join(PHASE_DIR, "rejected");
    const LINT_LOG_PATH   = path.join(PHASE_DIR, "lint-results.ndjson");
    const SMOKE = process.argv.includes("--smoke");

    // Import primitives from 181 harness
    const { loadGeistFont, extractGlyphs, getCapHeight } = await import(path.join(HARNESS_DIR, "geist-spine.mjs"));
    const { assembleLockup } = await import(path.join(HARNESS_DIR, "assemble-lockup.mjs"));
    const { lintCandidate } = await import(path.join(HARNESS_DIR, "lint.mjs"));
    const { R2_CONFIGS, generate } = await import(path.join(__dirname, "dirs/b-step-r2.mjs"));
    ```

    The orchestrator's main() function:
    1. Create CANDIDATES_DIR, REJECTED_DIR if they don't exist (fs.mkdirSync, recursive:true).
    2. Load Geist font (loadGeistFont()); extract glyphs for "accrue" (extractGlyphs()); get capHeight.
    3. For each config in (SMOKE ? [R2_CONFIGS[0]] : R2_CONFIGS):
       a. Call generate(config) from b-step-r2.mjs to get { markPathD, accentPathD, markWidth, markHeight }.
       b. Determine ink fill: colorTreatment "moss" → "#5E9E84"; else → "#181818".
       c. Determine accentFill: colorTreatment "two-tone" → "#5E9E84"; else → undefined.
       d. Call assembleLockup(markPathD, glyphs, { markWidth, markHeight, capHeight, gapRatio: 0.15, viewboxH: capHeight * 1.4, markIsTypemark: false, palette: { ink, paper: "#FAFBFC", accentFill }, accentPathD }) → lockupSvg string.
       e. Build monoSvgString: if config.monoMap has entries, replaceAll each [from,to] pair in lockupSvg.
       f. Build candidate object: { id: config.id, direction: "B", colorTreatment: config.colorTreatment, config, markPathD, accentPathD, markWidth, markHeight, lockupSvg, monoSvgString, capHeight, skipGapRatio: false, rationale: config.rationale }.
       g. Write lockupSvg to CANDIDATES_DIR/{id}.svg.
       h. If monoSvgString, write to CANDIDATES_DIR/{id}-mono.svg.
       i. Run lintCandidate({ id, direction: "B", svgString: lockupSvg, monoSvgString, skipGapRatio: false }); collect lint results.
       j. If any lint failure: move {id}.svg (and {id}-mono.svg) to REJECTED_DIR, write {id}-reason.txt, skip candidate.
       k. Append lint result line to LINT_LOG_PATH (NDJSON, one JSON object per line).
    4. Write CANDIDATES_DIR/index.json with the surviving candidates array (including colorTreatment and monoSvgString fields).
    5. Print summary: N raw, M passing, K culled with reasons.

    isMain guard: wrap main() call in `if (process.argv[1] === fileURLToPath(import.meta.url)) { main().catch(...) }` — per D-181-05 lesson.

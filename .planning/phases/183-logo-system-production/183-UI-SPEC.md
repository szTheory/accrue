# Phase 183 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase nature:** This is a **brand-asset production phase**, not an interactive screen/component phase. It mechanically derives the locked tournament winner (R2-7 — two-tone B1: 4-step rounded mark, Ink base, Moss accent on top step) into a committed SVG/PNG logo system at `brandbook/logo/`. There are no LiveView screens, no interaction states, and no shadcn/React/Vite/Tailwind surface in scope. The template dimensions below are mapped onto brand-asset semantics: **Spacing → mark geometry & lockup metrics; Typography → wordmark/subtitle type spec; Color → frozen brand palette & fills; Copywriting → asset-facing strings (subtitle, title/desc, README usage rules).**

## Spacing Scale

> Mapped to **logo geometry & lockup metrics**. The conventional 4px UI spacing scale does not apply — assets are vector, expressed in `viewBox` units and **ratios** so they scale losslessly. All values below are frozen in 182-FREEZE.md; the generator emits them, the executor must **not** hand-edit path data.

| Token | Value | Usage |
|-------|-------|-------|
| BASE_UNIT | 40 units | Mark `viewBox` is `0 0 40 40` |
| Step width (sw) | 10 units (0.25 × 40) | One stair tread; 4 steps = 40-unit mark width |
| Step height (sh) | 10 units (0.25 × 40) | One stair riser; 4 steps = 40-unit mark height |
| Corner radius (rr) | 0.5 units (min(sw,sh) × 0.05 curvature) | Softened step corners |
| gapRatio | 0.15 × capHeight | Mark-to-logotype gap in the lockup |
| Scale factor (s) | capHeight ÷ markHeight | Mark scaled onto `BASELINE = capHeight × 1.1` at render time |
| viewboxH | capHeight × 1.4 | Lockup vertical viewbox |
| **Clearspace** | **1 step-height (1× sh) on all four sides** | Same rule for icon-only mark and full lockup (one mental model, two contexts). Expressed as a **ratio**, never absolute px. Stated in words in `<title>`/`<desc>` so it can't drift. (D-13) |

**Raster target sizes (render-at-size, never downscale a large raster — D-09):**
favicon 16 / 32 / 48 px · apple-touch-icon 180×180 · icon-192 / icon-512 · social card 1200×630.

**Minimum sizes (single source of truth = `brandbook/README.md` "Logo usage" table, NOT the diagram — D-12/D-14):**
icon-only mark **16px** floor (favicon, validated PASS in 182-FREEZE — does not move) · primary lockup **120px** wide · with-subtitle lockup **168px** wide (below this, drop subtitle → use primary).

Exceptions: The 8-point UI spacing scale is intentionally **not** declared — it governs screen layout, which this phase does not produce. Geometry above is the binding spec.

## Typography

> Mapped to the **wordmark + subtitle type spec**. All letterforms ship as **outlined paths** (opentype.js, one path per glyph). No live text, no font embedding.

| Role | Size | Weight | Line Height / Spec |
|------|------|--------|--------------------|
| Logotype (wordmark) | capHeight-relative; "accrue" sets the cap height that drives all lockup metrics | Geist sans Regular (locked R1-C3) | Single line; greyscale fill `#181818` (sat=0, passes `lintMonochromeDeriv`) |
| Subtitle (with-subtitle variant only) | cap-height **0.42×** the logotype cap-height | Geist **Mono** Regular (400) | Stacked **below** the wordmark; baseline ≈ **0.55× logotype cap-height** below it; **left-aligned** to the wordmark's left edge; tracking **+0.02em**; **sentence case**; fill **Slate `#3A4754`** (D-07) |

**Type rules (binding):**
- Exactly **one** with-subtitle variant ships (`accrue-logo-subtitle.svg`).
- Subtitle uses **Geist Mono** (subordinates it to the Geist *sans* wordmark; reads as a dev-tool caption).
- Subtitle color is **Slate**, **never Moss** — Moss is barred sub-24px on light surfaces (BRAND-DNA usage rule).
- The tagline **"Billing state, modeled clearly." is NEVER welded to a lockup** — it is homepage/editorial typography only; documented as a usage rule in `brandbook/README.md` (D-06).
- Geist (sans + mono) provenance under OFL 1.1 → `brandbook/LICENSE-FONTS.txt`.

## Color

> Frozen brand palette (BRAND-DNA.md) and the R2-7 two-tone fill scheme (182-FREEZE.md). No new colors may be introduced. Default artwork = **light background, full color**; only the dark-bg exception earns an `-on-dark` filename (D-03).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (paper / light surface) | `#FAFBFC` (Paper) | Default artwork background; page base — never a text/fill color |
| Mark base / logotype (Ink) | `#181818` | Steps 1–3 of the mark + the "accrue" logotype (greyscale, sat=0; primary legibility path; ~17:1 on Paper) |
| Accent (10% — Moss) | `#5E9E84` | **ONLY** the topmost/rightmost step (step 4) of the mark, via `accentPathD`. Supplementary color cue, not a legibility path. |
| Subtitle neutral (Slate) | `#3A4754` | Subtitle text in the with-subtitle variant only (~7.8:1 on white, AAA) |
| Monochrome map | `#5E9E84` → `#818181` | Moss accent collapses to grey in mono variants (`*-mono`, `*-mono-inverse`) |
| Dark-surface artwork (`-on-dark`) | Ink-on-dark inversion per harness palette | Dark-background lockup + mark variants |

**Accent reserved for:** the single topmost step (step 4) of the logomark only — applied via the frozen `accentPathD`. Moss is **never** used for: the logotype, the subtitle, body-size elements, sub-24px text on light, or any rectangular container. (Container shapes behind the mark are barred by hard logo constraint #1.)

**Brand-palette guardrails (binding):**
- No rectangular background/container shape behind the mark (hard constraint #1).
- Logotype must sit optically close to the mark (hard constraint #2).
- Main lockup carries **no** subtitle (hard constraint #3; with-subtitle variant ships separately).
- Mark monochrome-derivable via `monoMap` — verify on the mono-derived SVG, not the color master.

## Copywriting Contract

> Mapped to **asset-facing strings** the suite must carry: the subtitle, accessible `<title>`/`<desc>`, and the README usage rules. There is no CTA / empty-state / error-state UI in this phase — those rows are marked N/A with rationale.

| Element | Copy |
|---------|------|
| Subtitle string (with-subtitle variant) | **"Billing for Elixir apps"** — functional descriptor (NOT the tagline); verbatim the brand book's #1 canonical short descriptor; Elixir-first per the locked BRAND-DNA qualifier rule. Sentence case, single line. (D-05) |
| Accessible `<title>` (per asset) | Describe the artwork concisely, e.g. "Accrue logo" / "Accrue logomark" / "Accrue logo, dark background" — every shipped SVG carries a `<title>`. |
| Accessible `<desc>` (per asset) | One sentence describing the mark + (for the clearspace asset) the clearspace **ratio rule stated in words** so the number can't drift. Exact `<desc>` wording is planner discretion (D-15). |
| README manifest / usage rules | `brandbook/README.md` is the **single source of truth** for: the manifest table (filename · role · when-to-use · format · provenance), all hard min-size numbers, the clearspace ratio, and the "tagline stays out of the lockup" rule. |
| Tagline (reference only — do NOT ship as a lockup) | "Billing state, modeled clearly." — editorial typography only; documented as a usage rule, never a file. |
| Primary CTA | N/A — no interactive surface in this phase. |
| Empty state | N/A — no data-bearing UI in this phase. |
| Error state | N/A — no runtime UI; "failure" here = a non-deterministic raster (caught by the CI `git diff --exit-code` gate over the artifact dir, D-11). |
| Destructive confirmation | N/A — no destructive user actions; the only irreversible step is committing assets, gated by review + visual-fidelity checkpoint (SC-4). |

**Naming grammar (binding — D-02/D-03/D-04):**
- Project-prefixed, kebab-case: `accrue-<role>[-<modifier>].svg`.
- `role` ∈ { `logo` = full lockup (mark + wordmark), `wordmark` = integrated typemark (type only), `mark` = icon only }.
- Modifiers ordered tone→background: `-mono` (single-ink positive), `-mono-inverse` (single-ink negative), `-on-dark` (dark-bg artwork). Default file = light-bg full-color; **do NOT** emit `-on-light`.
- Favicon set stays **bare/un-prefixed**: `favicon.svg`, `favicon.ico`, `favicon-16.png`, etc. (web-root convention).

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-184-04 | Repudiation | Non-deterministic generation hiding a real change in diff noise | mitigate | Sort keys (localeCompare), "\n" endings, single trailing newline, read $value.hex (RESEARCH Pitfall 5); Task 1 verify runs the generator twice and asserts `git diff --exit-code` clean. |
| T-184-05 | Tampering | Hand-editing tokens.css instead of tokens.json | mitigate | "GENERATED — do not edit" banner; CI determinism gate (Plan 05) would catch a hand-edit by regenerating and diffing. |
| T-184-06 | Spoofing | README claiming a scale value that drifts from theme.css | accept | Reference-only by design (D-11) — README points at --ax-* names; no minted values to drift. Low risk; PR review confirms. |
| T-184-SC | Tampering | npm/pip/cargo installs | mitigate | No new installs in this plan — deps already gated + locked in Plan 01 (T-184-SC). |
</threat_model>

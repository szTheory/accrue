## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-187-03-01 | Information Disclosure | screenshots | mitigate | Use only deterministic E2E fixtures and write screenshots under `accrue_admin/test-results/admin-baseline/`; do not commit PNGs. |
| T-187-03-02 | Tampering | raw cell observations | mitigate | Include manifest-owned `cell_id`, `surface`, `surface_type`, `mode`, `theme`, and `state` in every observation. |
| T-187-03-03 | Denial of Service | full matrix capture | mitigate | Follow D-06 representative manifest and D-10 targeted breakpoint scope; do not create a literal Cartesian product. |
| T-187-03-04 | Repudiation | gap/n/a cells | mitigate | Require `reason` or `notes` on every `gap` and `n/a` observation so Phase 192 comparison cannot drift. |
| T-187-SC | Tampering | npm/pip/cargo installs | mitigate | No package install is planned; use existing `@playwright/test` and `@axe-core/playwright` dependencies. |
</threat_model>

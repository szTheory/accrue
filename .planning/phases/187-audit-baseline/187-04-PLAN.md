<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| E2E login routes -> admin session | Test-only session helpers can simulate admin and non-admin users. |
| Browser actions -> LiveView state | Playwright probes trigger DOM patches, focus movement, overlays, and network state. |
| Trace/screenshots -> defect ledger | Generated evidence can contain sensitive values if run against non-test data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-187-04-01 | Elevation of Privilege | `e2e_plug.ex` login-member route | mitigate | Keep routes inside test support only; do not touch production router/auth; verify production files are unchanged. |
| T-187-04-02 | Spoofing | `e2e_auth_adapter.ex` member branch | mitigate | Use explicit token `"member"` and user id `e2e_member`; this branch exists only in E2E auth adapter. |
| T-187-04-03 | Information Disclosure | Playwright traces | mitigate | Use deterministic test fixtures and write traces under `accrue_admin/test-results`; commit only manifest references/checksums later. |
| T-187-04-04 | Denial of Service | live interaction probes | mitigate | Use stable baseline contracts, serial Playwright config, and observation rows for gaps instead of retry loops that hide defects. |
| T-187-04-05 | Tampering | interaction observations | mitigate | Each NDJSON line carries manifest `cell_id`, `overlay_tags`, expected, actual, and evidence_refs so Phase 187 artifacts can route defects. |
| T-187-SC | Tampering | npm/pip/cargo installs | mitigate | No package install is planned; rely on existing Playwright and Phoenix test support. |
</threat_model>

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`--ax-space-xs`) | Icon gaps, compact inline padding |
| sm | 8px (`--ax-space-sm`) | Compact element spacing, table/control gaps |
| md | 16px (`--ax-space-md`) | Default element spacing |
| lg | 24px (`--ax-space-lg`) | Section padding, toolbar rhythm |
| xl | 32px (`--ax-space-xl`) | Layout gaps, sidebar/card breathing room |
| 2xl | 48px (`--ax-space-2xl`) | Major section breaks |
| 3xl | 64px (`--ax-space-3xl`) | Page-level spacing |

Exceptions: no additional spacing-scale tokens are declared for Phase 188. Tiny optical adjustments, when unavoidable inside dense table internals, must be documented as one-off implementation exceptions rather than promoted to spacing tokens. Icon-only touch targets must stay at least 44px where they are primary interactive controls.

Reading measure: `--ax-measure: 68ch` must apply to prose, help text, error text, empty-state bodies, descriptions, and narrative table content. Do not globally cap raw tables or machine-data grids.

## Typography

Only these two weights are allowed in composed role bundles: regular 400 and semibold 600. Font roles must be consumed through `--ax-type-{role}-font`, `--ax-type-{role}-tracking`, and `.ax-type-{role}` utilities, not rebuilt with ad-hoc `font-size`, `font-weight`, `line-height`, `letter-spacing`, or `font-family`.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (`--ax-type-md`) | 400 | 1.4 (`--ax-leading-normal`) |
| Label | 14px (`--ax-type-sm`) | 600 | 1.4 (`--ax-leading-normal`) |
| Heading | 28px (`--ax-type-2xl`) | 600 | 1.2 (`--ax-leading-tight`) |
| Display | 36px (`--ax-type-3xl`) | 600 | 1.2 (`--ax-leading-tight`) |

Required composed role tokens: `body`, `body-sm`, `body-relaxed`, `label`, `label-sm`, `eyebrow`, `title`, `title-lg`, `heading`, `display`, `metric`, `code`, and `code-xs`.

Allowlist for raw type properties: `@font-face`, root body inheritance, icon/SVG mechanics, and documented one-off exceptions only. Tracking is separate from `font` shorthand and must use `--ax-type-{role}-tracking`.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--ax-base` light `#fafbfc`, dark `#0f1318` | Root background, page canvas, low-emphasis surfaces |
| Secondary (30%) | `--ax-elevated` light `#ffffff`, dark `#171d24`; `--ax-sunken` light `#f1f5f8`, dark `#0b1015` | Cards, sidebar, nav, panels, inset wells |
| Accent (10%) | runtime `--ax-accent`, default `#5D79F6`; filled controls use `--ax-accent-strong` + `--ax-accent-contrast` | Primary actions, links, selected nav, active filters, focus ring source, current-step indicators |
| Destructive | `--ax-danger`, readable/status pairs through `--ax-status-danger-*` | Destructive actions only |

Accent reserved for: primary CTA states, links, selected/active navigation, active filters, focus indication, command/search affordances, and current-step/progress emphasis. It must not become the default decoration for every interactive element.

Semantic role completion is part of this phase. Required roles must resolve in light, dark, and system-dark mode: focus ring/offset/shadow, scrollbar thumb/track/hover, disabled bg/border/text/opacity/cursor, readonly bg/border/text, interactive hover/active/selected, and `--ax-status-{success,warning,danger,info,neutral}-{bg,border,text,solid,on-solid}`.

Focus contract: use `:focus-visible` with a 2px visible outline plus offset and/or halo. Border-only focus changes are not sufficient.

## Phase 188 Root Contracts

### Typography Bundles

- Add composed tokens in `theme.css` using the two-token shape: `--ax-type-{role}-font` and `--ax-type-{role}-tracking`.
- Add `.ax-type-{role}` utilities and migrate primitives/semantic classes to consume role utilities or equivalent semantic selectors.
- Keep existing atomic tokens (`--ax-type-*`, `--ax-leading-*`, `--ax-tracking-*`, `--ax-font-*`, `--ax-measure`) as internal composition primitives.

### Layer System

Use this exact layer stack:

| Layer | Token | Value | Consumers |
|-------|-------|-------|-----------|
| Base | `--ax-z-base` | 0 | normal document flow, isolated local stacks |
| Sticky | `--ax-z-sticky` | 100 | topbar, skip link, mobile sidebar |
| Dropdown | `--ax-z-dropdown` | 200 | dropdown menus |
| Popover | `--ax-z-popover` | 300 | non-menu floating panels, help/dev/tab-more panels |
| Drawer | `--ax-z-drawer` | 400 | detail drawers |
| Modal | `--ax-z-modal` | 500 | command palette, step-up auth, modal dialogs |
| Toast | `--ax-z-toast` | 600 | flash/toast surfaces |

No ad-hoc overlay z-index literals may remain in admin CSS. Exceptions are local micro-stacking values `-1`, `0`, or `1` inside isolated components, documented inline and paired with `isolation: isolate` when needed. `--ax-z-topbar` may exist only as a deprecated alias to `--ax-z-sticky`.

### Motion

- Do not add a new motion family. Route transitions and animations through `--ax-dur-*`, `--ax-ease-*`, `--ax-rise-*`, `--ax-press-scale`, and `--ax-transition-*`.
- `prefers-reduced-motion` must collapse travel, transforms, and overshoot while preserving opacity crossfades.
- Raw `ms`, `s`, `cubic-bezier()`, and `transition: all` are banned except the documented skeleton loading loop.

### Tailwind Source Of Truth

- Delete `accrue_admin/assets/tailwind.config.js` and `accrue_admin/assets/tailwind_preset.js`.
- Keep `tailwindcss@3.4.17` only as the package-local CSS compiler/minifier.
- Remove `--config` from `mix accrue_admin.assets.build`.
- Docs must say package styles are authored only in `assets/css/theme.css` and `assets/css/app.css` using `--ax-*` tokens and `ax-*` classes. Host apps never configure Tailwind for `accrue_admin`.

### Verification Surface

The component kitchen must expose maintainer-facing foundation specimens for type roles, reading measure, focus, disabled/readonly, scrollbars, status roles, and representative layer values. Visual hierarchy in the kitchen must anchor first on the foundation specimen under inspection, then token evidence, then computed-state samples. Playwright checks should prefer computed styles over screenshot-only proof. Axe and reduced-motion coverage must continue to pass in light and dark.

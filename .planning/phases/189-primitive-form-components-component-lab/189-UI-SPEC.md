## Spacing Scale

All spacing consumed via `--ax-space-*` tokens in `theme.css`. The token layer
is frozen. Phase 189 adds no new spacing values.

### Pre-existing frozen foundation exception

`--ax-space-2xs` (2px) is a **frozen Phase-187/188 foundation token** declared in
`theme.css` lines 26-33. It is NOT introduced or modified by Phase 189. It exists
for dense micro-gaps (table cell internals, chip internals) that operate below the
grid-alignment concern WCAG applies to layout spacing. Phase 189 consumes this
token unchanged and declares no new sub-4px spacing values.

**Phase-189 spacing contract (values this phase adds or applies — all are multiples of 4):**

| Token | px equivalent | Usage in this phase |
|-------|---------------|---------------------|
| `--ax-space-xs` | 4px | Icon-to-label gap inside buttons; checkbox/radio internal gap |
| `--ax-space-sm` | 8px | Field help/error text margin-top; badge dot-to-label gap |
| `--ax-space-md` | 16px | Field stacking gap; state-grid cell internal padding |
| `--ax-space-lg` | 24px | Section-to-section gap in the lab renderer |
| `--ax-space-xl` | 32px | Family-to-family gap in the `.ax-dev-state-grid` renderer |
| `--ax-space-2xl` | 48px | Page-level lab section breaks |
| `--ax-space-3xl` | 64px | (unused in this phase) |

**Complete frozen token reference (for consumption traceability):**

| Token | px equivalent | Phase-189 status |
|-------|---------------|-----------------|
| `--ax-space-2xs` | 2px | Pre-existing frozen exception — Phase 187/188 origin; consumed unchanged; not declared by this phase |
| `--ax-space-xs` | 4px | Phase-189 contract — 4px multiple |
| `--ax-space-sm` | 8px | Phase-189 contract — 4px multiple |
| `--ax-space-md` | 16px | Phase-189 contract — 4px multiple |
| `--ax-space-lg` | 24px | Phase-189 contract — 4px multiple |
| `--ax-space-xl` | 32px | Phase-189 contract — 4px multiple |
| `--ax-space-2xl` | 48px | Phase-189 contract — 4px multiple |
| `--ax-space-3xl` | 64px | Phase-189 contract — 4px multiple |

**Touch target exception:** interactive controls (buttons, checkboxes, radio,
toggle, icon-buttons) must reach a 44px minimum touch-target height or width.
Padding should achieve this at mobile viewport (390px) without enlarging the
visible hit area via `min-height: 44px` on the control or its wrapping label.
This is a CMP-03 / WCAG 2.5.5 requirement, not a token addition.

Source: `theme.css` `--ax-space-*` declarations (lines 26-33); CMP-03.

### Accent reserved-for list

Accent (`--ax-accent`, `--ax-accent-strong`, `--ax-accent-readable`) is reserved
exclusively for:
1. Primary button fill (background: `--ax-accent-strong`)
2. Focused-control outline ring (`--ax-focus-ring` — same hue as accent)
3. Ghost/secondary button hover background (`--ax-interactive-hover`)
4. Selected toggle track background
5. Active sidebar link icon (already established in Phase 176)

Accent is NOT used for: status badges, helper text, error messages, read-only
surfaces, skeleton shimmer, or any non-interactive decorative element.

### Focus ring contract (Phase 188 D-20 — frozen)

Every interactive primitive must apply on `:focus-visible`:
- `outline: 2px solid var(--ax-focus-ring)` (light: `#174ea6`, dark: `#9bb5ff`)
- `outline-offset: 2px`
- `box-shadow: var(--ax-focus-shadow)` (4px halo at 24% opacity)
- Never use `outline: none` without a visible replacement

Source: `theme.css` semantic role tokens (lines 138-214 light, 218-276 dark);
Phase 188 D-17 through D-22; brandbook `tokens.json`.

## Component Inventory and State Matrix Contract

This section is Phase 189's primary design-contract addition. It defines the
complete state matrix every primitive must be verified against, and the exact
specimens the lab renderer must show.

### Frozen state taxonomy (from `baseline-manifest.js` COMPONENT_STATES)

| State | Applies to | Visual indicator | Token contract |
|-------|-----------|-----------------|----------------|
| `default` | All | Normal render | Component base tokens |
| `hover` | All interactive | Bg lightens; cursor: pointer | `--ax-interactive-hover` bg |
| `focus` | All interactive | 2px outline + halo | `--ax-focus-ring` + `--ax-focus-shadow` |
| `active` | Buttons, toggle, checkbox, radio | Bg darkens; scale 0.97 | `--ax-interactive-active`; `--ax-press-scale` |
| `pressed` | Buttons | Scale 0.97; bg: active | `--ax-press-scale: 0.97` |
| `disabled` | All controls | Flat bg; muted text; cursor: not-allowed | `--ax-disabled-*`; opacity `--ax-disabled-opacity: 0.62` |
| `loading` | Button, spinner | Spinner visible; button non-interactive | Spinner primitive; button aria-busy |
| `selected` | Radio, toggle-on, checkbox-checked | Accent fill or checkmark | `--ax-interactive-selected`; accent track |
| `empty` | Empty-state hero, json_viewer empty | Placeholder content; no affordance | No hover, no cursor: pointer on static hero |
| `error` | Input, textarea, select | Danger border + bg; error text visible | `--ax-status-danger-*`; aria-invalid="true" |
| `overflow` | Input, textarea, ID display, code | Content truncates; no clip; no layout break | `overflow: hidden; text-overflow: ellipsis; white-space: nowrap` on single-line; `overflow-wrap: anywhere` on multi-line |

States marked `n/a` in the registry must carry an explicit reason, per D-09 and
the established `admin-interactions.spec.js` pattern.

### State-grid lab renderer contract (`.ax-dev-state-grid`)

The new lab renderer replaces the current hand-authored sections for primitives.
Layout contract:
- One grid per component family
- Columns: 2 — left column is light theme scope, right column is dark theme scope
- Column theme scoping: each column wraps its cells in a `data-theme="light"` /
  `data-theme="dark"` container that genuinely re-scopes `--ax-*` tokens. The
  existing per-specimen `data-theme` wrappers were previously inert (D-07 gotcha)
  — the new renderer must resolve to different computed colors in each column,
  verified by the drift test's `getComputedStyle` delta assertion.
- Rows: one per applicable state; `n/a` rows rendered with muted label and stated
  reason
- Cell internal padding: `--ax-space-md` (16px) all sides
- Cell background: `--ax-base` (inherits from the theme column scope)
- State label: `.ax-type-code-xs` + `.ax-muted` color, rendered above the specimen
- Family section header: `.ax-type-eyebrow` (`label-sm` + uppercase + caps tracking)

The new grid renderer must satisfy these layout rules (to be added to `app.css`):

```
.ax-dev-state-grid {
  display: grid;
  grid-template-columns: 1fr 1fr;   /* light | dark */
  gap: 1px;                          /* 1px separator lines between cells */
  border: 1px solid var(--ax-border);
  border-radius: var(--ax-radius-md);
  overflow: hidden;
  background: var(--ax-border);      /* gaps show as border color */
}

.ax-dev-state-grid-col {
  display: flex;
  flex-direction: column;
  gap: 1px;
  background: var(--ax-border);
}

.ax-dev-state-grid-col[data-theme="light"],
.ax-dev-state-grid-col[data-theme="dark"] {
  /* The theme attribute on this element MUST re-scope the token layer.
     Implementation must wire to the same selector that html.accrue-admin[data-theme]
     uses — e.g. apply the dark-theme overrides when data-theme="dark" is present
     on any ancestor that matches the CSS selector chain. */
}

.ax-dev-state-cell {
  display: flex;
  flex-direction: column;
  gap: var(--ax-space-sm);
  padding: var(--ax-space-md);
  background: var(--ax-base);
  min-height: 4rem;

.ax-dev-state-cell-label {
  /* Uses .ax-type-code-xs + --ax-muted */
}

.ax-dev-state-cell-na {
  background: var(--ax-sunken);
  opacity: 0.6;
}
```

The `data-theme="dark"` column scope implementation is the D-07 critical path:
the column must visibly render dark-themed components, and the drift test must

## Accessibility Contract

All primitives must satisfy these invariants, verified by the Phase 189 e2e
suite (extending `admin-a11y.spec.js` and `admin-interactions.spec.js`):

| Invariant | Standard | Verification method |
|-----------|----------|---------------------|
| Focus ring visible: outline-width >= 2px | WCAG 2.4.11 (AA), WCAG 2.4.12 (AAA) | `getComputedStyle` probe: `outlineWidth >= "2px"` on `:focus-visible` |
| Focus ring offset >= 2px | WCAG 2.4.11 | `getComputedStyle` probe: `outlineOffset >= "2px"` |
| Accessible name present | WCAG 4.1.2 | axe-core `button-name`, `label`, `form-field-multiple-labels` rules |
| Button text contrast vs background >= 4.5:1 | WCAG 1.4.3 (CMP-04) | `getComputedStyle` color vs background; axe-core `color-contrast` |
| Disabled: no activation, no hover bg change | WCAG 1.4.3 (disabled excluded; CMP-04) | `elementFromPoint` + `dispatchEvent` probe |
| aria-invalid="true" on error inputs | WCAG 4.1.3 | axe-core `aria-allowed-attr`; `getComputedStyle` border resolves to danger token |
| aria-describedby linked to error message | WCAG 1.3.1 | axe-core `label`; manual probe |
| No misleading affordance on static elements | WCAG 4.1.2 | `getComputedStyle cursor` must not be `pointer` on badge, empty-state hero wrapper |
| No content clipped: scrollWidth <= clientWidth | CMP-02 | `elementFromPoint` overflow probe |
| Keyboard: Tab reaches all controls | WCAG 2.1.1 | Playwright `page.keyboard.press("Tab")` sequence |
| Keyboard: Space/Enter activates button | WCAG 2.1.1 | `dispatchEvent` keyboard probe |
| Checkbox: Space toggles | WCAG 2.1.1 | Keyboard probe |
| Radio: Arrow keys move selection | WCAG 2.1.1 | Keyboard probe |
| Reduced motion: shimmer travel = 0 | WCAG 2.3.3 | `reduced-motion.spec.js` extension |

## Root-Fix Enforcement Contract (CMP-05, D-14/D-15)

All fixes in this phase land exclusively at:
1. Component HEEx template (`.ex` files in `accrue_admin/lib/accrue_admin/components/`)
2. `theme.css` / `app.css` root token or class selectors

**Prohibited patterns (guarded by the new verifier + negative fixture):**
- Per-page CSS overrides of primitive `ax-*` classes
- Raw inline `style=` attributes on primitive components that set visual properties
- Raw `font-size`, `font-weight`, `line-height`, `letter-spacing`, `font-family`
  in component selectors outside the documented `ax-type-exception` allowlist
- Literal `z-index` values other than -1, 0, 1 in isolated component micro-stacking

The verifier guard for per-page-override detection follows the
`verify_package_docs.sh` verifier ↔ negative-fixture coupling pattern (Phase 188
D-15, already established for the typography-literal ban and no-literal-z-index guard).

## Viewports

Two frozen viewports from `baseline-manifest.js` PROJECTS (Phase 187, D-11):

| Viewport | Width | Usage |
|----------|-------|-------|
| Desktop | 1440px | Primary review; state grid full two-column layout |
| Mobile | 390px | Second review; state grid collapses to single column (light column only) OR stacks vertically |

**Mobile state-grid rule:** At 390px, the two-column state grid must not
squish components below their minimum functional width. The grid MUST either
stack columns vertically (light above dark) OR show light only with a "Dark"
tab toggle. Implementation choice is left to the planner (Claude's discretion),
but the mobile render must not break or clip any component specimen.

No additional breakpoints are introduced in this phase.

## Motion Contract

All transitions in primitive components route through existing Phase-174/177 atoms:

| Motion need | Token |
|-------------|-------|
| Button hover/press color change | `--ax-transition-colors` |
| Button press scale | `--ax-press-scale: 0.97` |
| Toggle track slide | `--ax-transition-base` |
| Input focus ring appear | `--ax-transition-colors` |
| Skeleton shimmer (exception) | `background-position` animation — the only allowed raw animation, documented exception |
| Tooltip appear | `--ax-dur-1 --ax-ease-out` opacity |

Under `prefers-reduced-motion`:
- Travel tokens (`--ax-rise-sm`, `--ax-rise-md`, `--ax-press-scale`) collapse to 0 / 1
- Duration tokens `--ax-dur-1`, `--ax-dur-3`, `--ax-dur-exit` collapse to 0ms
- Opacity feedback (`--ax-dur-2: 1ms`) remains perceptible

No new motion tokens. No raw `ms`, `s`, or `cubic-bezier()` literals.

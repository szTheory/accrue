<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Query modules to DataTable | Filter params and cursor state cross into rendered queue UI. |
| Billing records to display components | Row labels, IDs, status, and metadata render into table/card/detail DOM. |
| Responsive hidden DOM to keyboard/a11y tree | Desktop and mobile representations coexist in source markup. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-190-09 | Tampering | DataTable filters and cursor UI | mitigate | Preserve query module decode/encode and signed cursor boundaries; tests assert UI state only. |
| T-190-10 | Information Disclosure | rendered metadata and locators | mitigate | `data-component-group` values are static; no row IDs are embedded in group locators. |
| T-190-11 | Elevation of Privilege | hidden table/card controls | mitigate | CSS and Playwright follow-up assert inactive layout is not focusable or visible to keyboard users. |
| T-190-12 | Spoofing | selected/filter/sort states | mitigate | Selected/filter states use text, ARIA/current/pressed/count cues plus tokenized state color. |
| T-190-13 | Tampering | long metadata and timeline details | mitigate | HEEx escaping remains in place; tests keep script-like timeline text escaped. |
</threat_model>

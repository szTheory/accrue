<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server errors -> operator-visible copy | Error reasons must not leak secrets or raw internals. |
| Destructive action dialog -> mutation event | Copy informs explicit submit; it must not change authorization or action execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-191-10 | Information Disclosure | Error copy | mitigate | Replace raw visible `inspect(reason)` with resource/recovery copy; keep detailed diagnostics in logs where already present. |
| T-191-11 | Repudiation | Destructive confirmations | mitigate | Copy names billing effect and audit consequence before explicit submit. |
| T-191-12 | Spoofing | Permission/owner-scope copy | mitigate | Copy names owner scope/admin access boundary without implying access was granted. |
| T-191-SC | Tampering | package installs | mitigate | No dependency changes. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser DOM -> LiveView event loop | Playwright and user interactions trigger LiveView events through rendered controls. |
| Overlay shell -> background admin page | Modal/drawer state changes must suppress background click, hover, and focus while preserving explicit dismissal. |
| Action menu -> destructive billing actions | A menu item can reveal destructive flows but must not execute billing mutations directly. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-195-01 | Tampering | Drawer action host | mitigate | RED Playwright asserts no initial action forms and drawer-only form rendering before implementation. |
| T-195-02 | Elevation of Privilege | Destructive actions | mitigate | RED specs require destructive menu items to hand off to existing StepUp paths rather than direct execution. |
| T-195-03 | Tampering | Background page while drawer open | mitigate | RED tests require inert background, scroll lock, top hit-testing, and focus containment. |
| T-195-04 | Spoofing | Copy/action confusion | mitigate | RED specs require visible labels and context-carrying accessible names for drawer/action controls. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Overlay hook -> document scrolling | Hook mutates global document scroll and app-shell inert state. |
| Nested overlay -> lock counter | Multiple overlays can open before earlier overlays close. |
| Keyboard event -> LiveView close event | Escape must dispatch the same server close path as backdrop dismissal. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-195-13 | Denial of Service | ScrollLock | mitigate | Ref-count and reset tests prevent stuck locked body state after nested overlays. |
| T-195-14 | Tampering | Background app shell | mitigate | ScrollLock sets and clears `inert` on `#accrue-admin-shell` only while locked. |
| T-195-15 | Spoofing | Focus containment | mitigate | Overlay hook reuses FocusTrap Escape/focus behavior rather than inventing a new keyboard path. |
| T-195-16 | Information Disclosure | Global styles | accept | Scroll compensation CSS variable carries no user data and is local to document styling. |
</threat_model>

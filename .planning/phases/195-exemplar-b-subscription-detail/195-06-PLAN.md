## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Summary row action -> LiveView event | Row-level Change/View controls push events or links from the summary header. |
| Action menu -> LiveView event | Menu buttons trigger drawer selection events. |
| Menu disclosure -> page focus | The menu is non-modal and must not suppress the page like a dialog. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-195-21 | Spoofing | Row-level Change labels | mitigate | Hidden context names the affected subscription/action. |
| T-195-22 | Tampering | Action menu item values | mitigate | Component only emits item values; Plan 07 keeps server-side action allowlists. |
| T-195-23 | Denial of Service | Action menu focus | accept | Native details plus existing dropdown.js dismissal is sufficient for lightweight menu scope. |
| T-195-24 | Elevation of Privilege | Danger menu items | mitigate | Danger styling and grouping only reveal drawer/StepUp flow; no direct mutation in component. |

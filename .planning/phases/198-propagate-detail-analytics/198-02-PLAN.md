## ASVS Context

ASVS level: 1. Block threshold: high severity.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL params to Customer subviews | Untrusted `tab` values select visible record collections and must not hide primary state. |
| LiveView event to action execution | Forged or stale action events can target hidden or unavailable invoice, charge, replay, override, or payment-method actions. |
| Admin action to audit/step-up | Sensitive actions require fresh identity proof and preserved audit rows. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-198-05 | Elevation of Privilege | Invoice/charge/webhook/connect actions | mitigate | Tests require `StepUp.require_fresh/4` challenge behavior for destructive, money-moving, replay, and fee override actions. |
| T-198-06 | Tampering | Hidden or omitted action events | mitigate | Tests require server-side action validity, not only absent UI controls. |
| T-198-07 | Information Disclosure | Raw payload and metadata | mitigate | Tests require lazy bottom rendering for raw JSON and activity. |
| T-198-08 | Spoofing | Customer navigation | mitigate | Tests remove misleading broad `More` peer bucket and require exact peer labels. |
| T-198-SC | Tampering | package installs | accept | No package installs are planned. |
</threat_model>

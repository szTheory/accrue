## ASVS Context

ASVS level: 1. Block threshold: high severity.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser action event to invoice mutation | Invoice lifecycle events can void, finalize, pay, or mark records and must be revalidated server-side. |
| Browser refund form to billing mutation | Refund amount/reason/source-event fields are untrusted LiveView event params. |
| Raw invoice/charge data to admin browser | Raw payloads and timeline details must remain escaped and lazy. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-198-17 | Tampering | Invoice action events | mitigate | Re-check status/action availability in LiveView handlers before execution. |
| T-198-18 | Elevation of Privilege | Invoice danger actions and charge refund | mitigate | Preserve `StepUp.require_fresh/4` for void, mark-uncollectible, and refund. |
| T-198-19 | Repudiation | Invoice and refund audit rows | mitigate | Preserve existing audit recording helpers and tests around action completion. |
| T-198-20 | Information Disclosure | Invoice/charge raw data | mitigate | Raw JSON renders only in lazy bottom section with existing JsonViewer escaping. |
| T-198-SC | Tampering | package installs | accept | No package installs are planned. |
</threat_model>

## ASVS Context

ASVS level: 1. Security block threshold: high.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Overlay component to document root | LiveView portal content crosses out of page wrappers into `#ax-overlay-root`. |
| JS hook to browser globals | Scroll/focus hooks mutate `documentElement`, `body`, shell inertness, and active focus. |
| Command palette to global search | Global keyboard shortcuts open a dialog-like surface from anywhere in the admin UI. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-199-07 | Tampering | ScrollLock | mitigate | Ref-counted unit tests require final-only restore and cleanup of inert/style state. |
| T-199-08 | Spoofing | Overlay stacking | mitigate | Browser hit-test checks require panel controls above scrim and body-level portal root. |
| T-199-09 | Denial of Service | FocusTrap | mitigate | Unit/browser tests require Escape close, focus restore, and no body focus after close. |
| T-199-10 | Elevation of Privilege | Hidden test mirrors | mitigate | Source tests require mirrors to stay hidden and aria-hidden so they are not interactive runtime paths. |
| T-199-11 | Information Disclosure | Command palette | mitigate | Command palette stays subject to dialog close/focus cleanup and existing scoped search behavior. |
| T-199-SC | Tampering | package installs | accept | This plan adds no package-manager installs. |
</threat_model>

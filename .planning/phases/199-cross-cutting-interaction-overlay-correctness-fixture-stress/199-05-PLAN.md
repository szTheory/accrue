## ASVS Context

ASVS level: 1. Security block threshold: high.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Copy source to rendered UI | Copy modules determine operator instructions, action labels, and state/error guidance. |
| Hidden context to assistive tech | Visually hidden labels affect accessible names for repeated action controls. |
| Generated fixtures to browser tests | Exported copy strings are committed and consumed by browser anti-drift checks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-199-21 | Spoofing | Repeated action labels | mitigate | Component and browser tests require object/action context for compact labels. |
| T-199-22 | Repudiation | Sensitive confirmations | mitigate | Copy names billing effect, affected object, and next action in confirmations. |
| T-199-23 | Information Disclosure | Error and permission copy | mitigate | Copy tests require precise but non-sensitive state messages; no raw backend identifiers in generic errors. |
| T-199-24 | Tampering | Generated copy fixture | mitigate | Export task regenerates committed fixture and `git diff --check` verifies output. |
| T-199-25 | Denial of Service | Final focused gates | mitigate | Closeout runs focused commands and records unrelated broad-suite failures without expanding scope. |
| T-199-SC | Tampering | package installs | accept | This plan adds no package-manager installs. |
</threat_model>

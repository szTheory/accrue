- `slug(value)` — reimplement byte-identically to `baseline-manifest.js:192-197` (lowercase → `[^a-z0-9]+` to `-` → strip leading/trailing `-`). Do NOT import it from the frozen manifest (it is not exported there).
- `claimKey(surface, dimension, region_tag, overlay_tags)` — canonical D-01 string: `` `${slug(surface)}__d${String(dimension).padStart(2,"0")}__${region_tag || "noregion"}__ov-${normalizeOverlays(overlay_tags).join("+") || "none"}` ``. Overlays are deduped with `Array.from(new Set(...))` and sorted with the DEFAULT codepoint `.sort()` (NEVER `localeCompare` — locale-sensitivity is a determinism bug per RESEARCH anti-patterns).
- `findingId(claim_key)` — `"f-" + createHash("sha256").update(claim_key, "utf8").digest("hex").slice(0,16)`.
- `assertDimension(d)` — return `d` if an integer in 1..12, else throw (`dimension ∉ 1..12`).

- `normalizeOverlays(tags)` — for each tag, throw if ∉ `OVERLAY_TAGS`; dedup; codepoint `.sort()`; empty/undefined → `[]`.
- `isAdmissibleToken(token)` — true iff token is exactly `rubric-dim-below-bar`, `token-bypass`, or matches `persona-job-miss:<job>` (prefix `persona-job-miss:`); false otherwise (used by the D-16 parse-time drop gate).

Export all vocabularies, maps, and functions plus `runSelfTest` (added in Task 2) via `module.exports`.

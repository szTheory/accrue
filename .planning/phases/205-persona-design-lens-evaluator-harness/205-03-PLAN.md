| Boundary | Description |
|----------|-------------|
| screenshot text → model instructions | In-screenshot text is attacker-influenceable and must be treated as data, never instructions |
| model output → candidate identity/CI | Model output is advisory; identity is re-derived, and the LLM never gates CI (worklist only) |
| oversized image → process | Per-image base64 must be bounded |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-205-01 | Tampering / Elevation | persona lens call + parse | high | mitigate | System preamble marks in-screenshot text as untrusted data; harness ignores model-supplied identity and re-derives `claim_key`/`finding_id`; `justification_token` deterministic parse gate + taste denylist drop rows pre-human; LLM output is a proposer worklist, never a CI gate. |

| T-205-03 | Denial of Service | per-image base64 | medium | mitigate | `MAX_B64_BYTES` 5 MB guard preserved verbatim; oversized images skipped with a warning. |

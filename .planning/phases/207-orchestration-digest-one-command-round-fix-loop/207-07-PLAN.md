<objective>
Close CR-01 from `207-VERIFICATION.md`: `ratchet-digest.mjs` currently rejects real ledger rows when `suggested_fix` is `null`, even though `ratchet-propose.mjs` legitimately emits `suggested_fix:null` when the model omits that optional field. The gap-closure target is narrow: keep the digest strict about identity, location, severity, frequency, and defect prose while treating `suggested_fix` as optional rendered prose.

Purpose: the phase goal depends on `mix accrue_admin.ui.round` always producing the digest before deciding whether to raise. A nullable optional prose field must not abort the maintainer's read surface.
Output: an updated digest validator/render path plus a regression self-test proving null `suggested_fix` no longer prevents digest generation.
</objective>

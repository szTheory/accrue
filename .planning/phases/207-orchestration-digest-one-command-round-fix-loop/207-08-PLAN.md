<objective>
Close CR-02 from `207-VERIFICATION.md`: the guard-mint path can write structurally incomplete concrete rows into committed guard-home specs when the scoped probe reports `present:false` without the fields required by that guard kind. Also close WR-02 from the same verification report's mutation-command warning: `ui.fix` currently stages only `priv/static` but commits without a pathspec, so unrelated pre-staged files can be swept into the CSS commit.

Purpose: ORCH-05 requires deterministic guards that prevent silent reopen without corrupting CI specs, and ORCH-04 requires the mutation command to keep its source/CSS commit scoped.
Output: guard-mint required-field validation plus regression self-tests, and a pathspec-scoped `git commit` step in `mix accrue_admin.ui.fix`.
</objective>

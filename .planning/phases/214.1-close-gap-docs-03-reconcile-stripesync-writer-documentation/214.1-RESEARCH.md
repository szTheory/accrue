### Pattern 1: Semantic documentation contract

**What:** Require small affirmative facts and reject known-stale claims, instead of snapshotting an entire paragraph. [VERIFIED: codebase grep]

**When to use:** For public documentation whose wording may be refined without changing a behavioral truth. [VERIFIED: codebase grep]

**Example:**

```bash
# Source: scripts/ci/verify_package_docs.sh
require_fixed "$stripe_sync_ex" "client-backed pull refresh"
require_fixed "$stripe_sync_ex" "Accrue.Entitlements.Reconcile"

```

Use stable diagnostic labels in the `fail` output so the fixture asserts a bounded actionable substring, rather than shell implementation detail. [VERIFIED: codebase grep]

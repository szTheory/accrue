<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| host configuration → source registry | Configured source data is untrusted and must resolve to closed types or fail typed. |
| source outcome → host/UI/lifecycle caller | A capability result may trigger user guidance or dangerous provider-specific control. |
| runtime registry → docs/matrix | Drift can mislead hosts into invoking unsupported or wrong-rail operations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-215-13 | Elevation of Privilege | Apple capability dispatch | high | mitigate | `source_test.exs` processor-call traps plus `entitlement_source_matrix_guard_test.exs` fail closed on every injected Apple-to-Stripe mutation family. |
| T-215-14 | Tampering | capability vocabulary/docs | high | mitigate | `verify_entitlement_source_matrix.sh` and mutation tests fail closed on missing, reordered, booleanized, or divergent closed values. |
| T-215-15 | Spoofing | configured source registry | medium | mitigate | Reject null/empty/duplicate/unknown sources and require typed source identity on every outcome/error. |
| T-215-16 | Information Disclosure | guidance/outcomes | medium | mitigate | Return stable bounded guidance/reason fields only; no raw evidence or provider payloads. |

## ASVS L1 Control Mapping

| ASVS control | Applicability | Executable evidence / fail-closed gate |
|---|---|---|
| V2 Authentication | Not directly applicable | Source inspection does not authenticate; authenticated rail observations remain an upstream requirement and cannot be synthesized by this registry. |
| V3 Session Management | Not directly applicable | No session or reconciliation credential is stored; source outcomes only describe ownership and next action. |
| V4 Access Control | Applicable | Closed typed outcomes and processor-call traps prevent an Apple observation/management result from gaining Stripe mutation authority (T-215-13). |
| V5 Input Validation | Applicable | Null, empty, duplicate, unknown, reordered, and booleanized registry/fixture inputs fail typed or fail the automated matrix gate (T-215-14/T-215-15). |
| V6 Cryptography | Not directly applicable | The registry handles bounded capability metadata only and never accepts keys, JWS, receipts, or provider payloads. |
</threat_model>

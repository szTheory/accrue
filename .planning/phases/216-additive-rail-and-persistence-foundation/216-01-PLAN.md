<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| host config → `Accrue.Config` | Host-owned values select rail/source/environment and cross the boot-validation boundary. |
| host identity → host Repo | Host-authenticated owner strings become an opaque durable account UUID. |
| Ecto changeset → PostgreSQL | Competing account writes cross from application validation to the database concurrency authority. |

| T-216-01 | Tampering | `Accrue.Config` default rail | high | mitigate | D-02 boot validation requires an explicit registered controllable default whose processor matches the unchanged alias; the tracer test proves the valid path and Plan 216-02 proves rejection paths. |
| T-216-02 | Spoofing | `Entitlements.Account.fetch_or_create/3` | medium | mitigate | Accept only host-supplied owner type/id at this storage boundary, create an opaque UUID, expose no unauthenticated owner lookup, and document that host authentication precedes this call. |

| T-216-SC | Tampering | package-manager installs | low | accept | No npm, pip, cargo, or new Mix package installation occurs in this phase. |

## Trust Boundaries

| Boundary | Description |
|---|---|
| provider-normalized attributes → observation changeset | Optional identities and evidence references arrive as untrusted strings before durable storage. |
| observation → grant | A caller-selected observation UUID becomes provenance for an account/rail/environment-qualified grant. |
| Ecto/direct SQL → PostgreSQL | Application validation can be bypassed by `insert_all`, SQL, races, or later bulk writers; PostgreSQL is the concurrency and domain authority. |
| migration → host-owned Repo | Prefix-qualified constraints alter an adopter-owned database through Accrue's additive migration stream. |

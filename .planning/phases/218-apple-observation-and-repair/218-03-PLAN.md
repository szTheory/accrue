## Trust Boundaries

| Boundary | Description |
|---|---|
| internet signedPayload -> verifier | Opaque attacker-controlled bytes claim Apple authority. |
| x5c/certificate claims -> normalized facts | Algorithm, chain, app, and environment confusion can forge access. |
| durable result -> HTTP acknowledgement | Premature success can lose evidence; unbounded quarantine can exhaust storage. |

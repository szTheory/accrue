- API coverage: preserve `COVERAGE.md`; the capability matrix already integrates history, repeated transactions, refund/revocation evidence, and product mapping behavior.
- Schema-push detection: not applicable; no ORM schema or migration file is modified.
- Reversibility: the nil-mapping flow is a local correction behind existing private modules and closed outcome atoms; no checkpoint is warranted.

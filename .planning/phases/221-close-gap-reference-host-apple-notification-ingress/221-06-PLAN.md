## Trust Boundaries

| Boundary | Description |
|---|---|
| Runtime environment → host configuration | Untrusted deployment strings select accepted plans and trusted network peers. |
| Direct TCP peer → forwarded request metadata | Only an explicitly trusted proxy may supply a client identity; all client-supplied forwarding metadata is untrusted. |
| Apple product ID → entitlement plan | A verified product identifier may map only to a configured local entitlement plan before admission. |
| Host limiter → distributed deployment | Process-local pressure is advisory defense-in-depth; edge/shared infrastructure owns fleet-wide enforcement. |

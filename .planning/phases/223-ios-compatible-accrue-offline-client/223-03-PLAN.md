<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| host transport → reconnect facade | Transport is trusted only to authenticate/request; returned bytes remain untrusted proof input. |
| host Keychain policy → Apple helper | Service, access group, and accessibility are host-controlled integration inputs. |
| Apple OSStatus → public outcome | Platform diagnostics are reduced to bounded actionable values without secret leakage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-223-10 | Elevation of privilege | reconnect response | high | mitigate | Delegate all response bytes to `applyServerProof`; no reconnect-only metadata or cache entry point. |
| T-223-11 | Spoofing | host transport boundary | high | transfer | Host owns authenticated transport and account credentials; package documents and types only the byte-returning seam. |
| T-223-12 | Tampering | concurrent reconnect | high | mitigate | Reuse serialized persisted high-water, signed-deny order, and atomic store; cover races with async tests. |
| T-223-13 | Information disclosure | Keychain helper | high | mitigate | Policy-only API performs no key generation/persistence/fetch/logging and exposes bounded OS outcomes. |
| T-223-14 | Elevation of privilege | Keychain accessibility fallback | medium | mitigate | Closed explicit ThisDeviceOnly enum and tests forbid implicit/migratable downgrade. |
| T-223-SC | Tampering | package dependencies | low | accept | Security is an Apple system framework; no package installation or third-party dependency is added. |
</threat_model>

## Trust Boundaries

| Boundary | Description |
|---|---|
| candidate/transaction sidecars → canonical cache | Sidecars are untrusted until their transaction record and prior envelope authenticate for the configured canonical path; no candidate may become authority through recovery. |
| late filesystem error → rollback state machine | Replacement, rollback overwrite, and directory synchronization can fail independently; every error must preserve a recoverable authenticated prior and remain observable. |
| concurrent compact proofs → verifier/admission | Independently signed bytes are still untrusted until exact profile/account/device/time checks succeed; scheduling cannot confer authority. |
| test harness process → public result/display seam | Exit status may expose bounded success/failure only; proof/key/envelope/OS/remote diagnostic material must not cross the process or UI-facing boundary. |

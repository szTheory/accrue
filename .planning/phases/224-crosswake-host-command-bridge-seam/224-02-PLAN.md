<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| manifest/registry configuration → runtime authority | Configuration is not authoritative until uniqueness, literal command membership, descriptor shape, and exact version intersection are validated. |
| active route → asynchronous host work | Authority may expire while native work is pending; cancellation cannot be trusted as termination. |
| host outcome → WebKit reply | Host output is untrusted until descriptor validation and binding revalidation; only Crosswake can terminalize. |
| bridge events → telemetry sink | Operational fields cross into host-owned logging and must be structurally data-minimized. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-224-05 | Elevation of privilege | capability/registry | high | mitigate | Literal four-command membership plus active-manifest ∩ exact registry/version; setup rejects duplicates and malformed descriptors. |
| T-224-06 | Tampering | route-bound result | high | mitigate | Navigation invalidates/cancels by epoch and the terminalizer rechecks exact origin/manifest/route/epoch immediately before reply. |
| T-224-07 | Tampering | duplicate completion | high | mitigate | One private atomic/actor-isolated terminal claim owns every success, denial, throw, cancellation, and late outcome. |
| T-224-08 | Information disclosure | payload and telemetry | high | mitigate | Fixed no-field schemas, stable denial codes, and telemetry field allowlists; structural negative fixtures exercise sensitive classes. |
| T-224-09 | Repudiation | command operation | medium | mitigate | Bounded correlation ID, route epoch, command/version, terminal reason, and duration distinguish attempts/results without logging payload or identity. |
| T-224-SC | Tampering | source revision | high | mitigate | Each task reviews and commits the patch, updates audit/diff/lock, and the runner refuses non-matching source before tests. |
</threat_model>

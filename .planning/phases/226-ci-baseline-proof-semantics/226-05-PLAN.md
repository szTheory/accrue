## ASVS L1 posture and block threshold

Security enforcement is OWASP ASVS Level 1. Any unresolved high or critical threat blocks plan completion; medium and low threats require the recorded disposition and automated mitigation/acceptance evidence.

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| GitHub/fixture responses → collector | Provider-controlled status, pagination, timestamps, names, and JSON cross into repository tooling. |
| Collector → durable record | Only exact-schema metadata may cross; unknown content and incomplete lists must be rejected. |
| Policy manifest → proof/timing derivation | Checked-in lane roles determine proof eligibility, initial queue roots, and staged-chain membership. |
| Durable record → validator/Phase 227 | Downstream decisions trust proof, queue, chain, signature, and provider facts only after independent recomputation. |

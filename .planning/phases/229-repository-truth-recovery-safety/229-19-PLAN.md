<threat_model>
## OWASP ASVS L1 Trust Boundaries

| Boundary | Description |
|---|---|
| caller paths/private authority → first wrapper write | Every path and identity must be pinned and non-aliasing before mutation is possible. |
| child chain → canonical pair/workspace | Outputs publish transactionally while all unrelated tracked/index/workspace state stays exact. |
| final attestation → strict verifier | Attestation bytes are untrusted until exact schema/digest/output/authority bindings are independently recomputed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-229-G19-01 | Elevation of Privilege | output/authority aliases | high | mitigate | Pin canonical paths and reject physical, symlink, hardlink, same-file, capsule, and authority aliases before writes. |
| T-229-G19-02 | Tampering | canonical publication | high | mitigate | Verify exclusive temporaries then use atomic rename with exact pair rollback on every failure. |
| T-229-G19-03 | Tampering | tracked/index/workspace state | high | mitigate | Exact NUL-safe status/index/tracked/untracked/ref/worktree snapshots with two-path-only transitions. |
| T-229-G19-04 | Spoofing | final attestation | high | mitigate | Construct and independently verify exact canonical bytes and all authority/output/snapshot digests. |
| T-229-G19-05 | Repudiation | test authority | high | mitigate | Inject mutations around the actual wrapper process and prove complete rollback/no PASS. |
| T-229-G19-06 | Information Disclosure | docs and process output | medium | mitigate | Commit only variable/flag names and sanitized errors; never runtime paths or private content. |
</threat_model>

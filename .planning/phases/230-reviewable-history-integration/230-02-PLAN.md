## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote (`origin`) → local refs | Untrusted upstream content becomes the second merge parent |
| CLI argv → git plumbing | Operator-supplied ref names and paths reach `git` |
| Repository state → committed public evidence | Object ids, paths, and command records become a committed public artifact |
| Subject repository → scratch clone | Repository content is copied into a scratchpad location outside version control |

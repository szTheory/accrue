<objective>
Recompute the full hazard universe of the candidate merge from live SHAs and give every hazard an evidence-backed, machine-recomputable disposition.

Purpose: a textually clean merge is not a safe merge. D-14 redefines "conflict disposition" for a clean merge — every place both histories had an opinion, or where one side's change silently changes the other side's meaning, needs a recorded resolution. D-15 forbids transcribing the universe: this exact discussion proved transcription rots when `origin/main` moved mid-session and a sixth co-touched file appeared. D-16 forbids asserting convergent-identity: it must be proved by blob object id.

Output: the `hazards` section of `230-INTEGRATION-DISPOSITION.{json,md}`, the closed hazard-class enumeration, exact-set completeness assertions, and a maintainer-legible rendering.
</objective>

## Trust Boundaries

| Boundary | Description |

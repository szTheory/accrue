<objective>
Retire both broken module-boundary guard idioms across every git-tracked `scripts/ci/*.mjs`
entrypoint, and close the vacuous-test class in the same commits.

Purpose: D-27/D-28/D-31/D-33. A guard that evaluates `false` turns a merge-blocking gate into a
silent exit 0, and a file that "passes" `node --test` with zero real tests is the same lie in a
different costume. Fixing the guard alone on a vacuous file trades a loud accident for a quiet
nothing (D-31), so the two fixes are same-commit coupled per file.

Output: one shared guard across the tree, at least one prose-named test per file, and explicit TAP
reporter selection wherever child test output is parsed.
</objective>

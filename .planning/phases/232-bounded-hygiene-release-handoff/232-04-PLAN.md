<objective>
Make the window-disposition renderer tell the truth about which gate outcomes it is describing, and
prove both directions of the mapping with a derived-legality test.

Purpose: D-13/D-14/D-15/D-18/D-20 and the CR-01 follow-through. The current bucketing is an if-chain
with fall-through whose unreachability is recorded in a comment, and comments do not fail CI. The
headings name status words rather than what happened, so a reader without the schema cannot read the
report.

Output: a total `(disposition, state)` pair map that fails closed, a cartesian-product test asserting
reachability in both directions, D-15's four named sections, and a presentation-only re-render of
phase 231's artifact that touches no JSON byte.
</objective>

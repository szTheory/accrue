<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub API + token -> readiness script | A repo-scoped token crosses into the script; its value must never reach stdout, a log file, or a committed artifact. |
| release-please stdout -> release decision | The tool only warns on a truncated commit window, so its output is trusted input that must be validated, not scanned optimistically. |
| CI step condition -> required check | A token-gated step that skips quietly can be mistaken for a step that ran and passed. |

<objective>
Act on the classification from plan 232-07 under a fail-closed bounded-cleanup contract: every cleanup
commit carries a finding row naming the command it fixed, passes are capped at two, and the pinned
worktree authority is recaptured in the same commit that makes the tree clean.

Purpose: D-49 through D-58, plus the recorded handoff that fully cleaning the tree flips a pinned
boolean and will fail strict re-verification unless the recapture is same-commit. The operational test
for objectivity is deliberately narrow: a finding qualifies if and only if a named command exits
non-zero now and exits zero after. "I noticed X while fixing Y" is the exact mechanism by which bounded
passes become unbounded, so it is prohibited rather than discouraged.

Output: a committed findings ledger, its join assertion, the two missing Stripe fixture scripts in the
tree, the degraded shadow removed, and a recaptured inventory.
</objective>

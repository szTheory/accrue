## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external webhook request -> `Webhook.Plug` | Untrusted internet input crosses into the billing system |
| `Webhook.Plug` -> `Webhook.Signature` | Signature verification decides whether stateful processing is allowed |
| `DefaultHandler` -> local billing tables | Parsed lifecycle data mutates trusted persisted subscription/invoice state |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-96-05 | T | `webhook/default_handler.ex` | mitigate | Reuse stale-event guards and canonical refetch so replayed or out-of-order Braintree webhooks do not overwrite newer state blindly. |

</threat_model>

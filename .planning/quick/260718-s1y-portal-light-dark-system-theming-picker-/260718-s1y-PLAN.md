# Quick Task 260718-s1y — Plan

## Goal
`accrue_portal` (`/billing`) currently renders dark only via `@media (prefers-color-scheme: dark)` in core
`brand.css` — it follows the OS with no override, no light control, no picker. The layout already sets
`<html data-theme={@theme}>` from the `accrue_theme` cookie (`Accrue.Portal.BrandPlug`, default "system"),
but the CSS ignores `[data-theme]`. Add real **light + dark + system** theming driven by an idiomatic
**picker**, persisted via the existing cookie, with the host brand accent legible in **both** modes.
Library-only (core `accrue` + `accrue_portal`); no host change.

## Tasks

### Task 1 — Three-state theming + brand-in-both-modes tokens
- **files:** `accrue/priv/static/brand.css`
- **action:** ADDITIVE ONLY (keep existing `--accrue-*` names). Replace the single OS-only dark block with a
  three-state model:
  - `:root` keeps light defaults.
  - `:root[data-theme="dark"]` → dark tokens (explicit; wins even on light OS).
  - `@media (prefers-color-scheme: dark) { :root[data-theme="system"], :root:not([data-theme]) { …same dark
    tokens… } }` → system mode follows OS; scoping to `system`/no-attr means an explicit `data-theme="light"`
    stays light on a dark OS. (Duplicate the ~8 dark vars across the two selectors — fine for this build-less
    file.) Dark vars are the current set: `--accrue-ink #ECF1F5`, `--accrue-slate #B7C2CC`,
    `--accrue-surface #171B20`, `--accrue-surface-muted #10141A`, `--accrue-border #2A333D`, plus the dark
    `--accrue-shadow`.
  - Add brand-in-both-modes tokens:
    - `--accrue-brand-accent-text`: light `var(--accrue-brand-accent)`; dark
      `color-mix(in srgb, var(--accrue-brand-accent) 60%, #ECF1F5)`.
    - Make `--accrue-brand-accent-strong` derive from accent: light
      `color-mix(in srgb, var(--accrue-brand-accent) 82%, black)`; dark
      `color-mix(in srgb, var(--accrue-brand-accent) 82%, white)`. (Replaces the fixed `#4D8A70` so hover
      tracks any host accent.)
  The host's inline `:root{--accrue-brand-accent:…}` override still wins in both modes (custom-prop refs
  resolve to the cascaded accent).
- **verify:** `cd accrue && mix compile` clean; grep confirms `data-theme="dark"`, `data-theme="light"`,
  `data-theme="system"`, and `--accrue-brand-accent-text` all present.
- **done:** Light/dark/system all reachable via `[data-theme]`; accent-text + derived accent-strong defined.

  recolors per theme + brand.
- **verify:** `cd accrue_portal && mix compile` clean.
- **done:** Eyebrow/links legible in both modes; picker styles present.

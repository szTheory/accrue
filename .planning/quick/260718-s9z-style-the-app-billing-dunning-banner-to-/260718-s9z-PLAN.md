# Quick Task 260718-s9z — Plan

## Goal
The "Action Required: We were unable to process your recent payment…" line on `/app/billing` renders as raw
unstyled text, full-bleed at the left edge. Root cause: the host `Layouts.app/1` calls the **headless**
`AccrueAdmin.Components.DunningBanner.dunning_banner customer={customer}` with **no inner block**, so it falls
through to the component's default `ax-banner ax-banner-danger` markup — accrue_admin design-system classes the
Cadence host never loads (host uses its own daisyUI/Tailwind bundle). Fix host-side: pass a Cadence-styled
slot and align the banner with the content column. Demo/host-only; no library change.

## Task

### Task 1 — Pass a Cadence-styled slot + align to the content column
- **files:** `examples/accrue_host/lib/accrue_host_web/components/layouts.ex` (the `app/1` function, ~lines 36-49)

  to INSIDE the `<div class="mx-auto max-w-6xl space-y-4">`, as its first child (so it aligns with the page
  cards and gets `space-y-4` spacing). KEEP the `<%= if customer = dunning_customer(@current_scope) do %>`

  `Accrue.Dunning.requires_attention?/1` gate still controls visibility). Pass a styled inner block built from

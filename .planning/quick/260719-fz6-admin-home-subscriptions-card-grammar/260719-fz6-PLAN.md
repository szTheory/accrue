## Goal

The admin **Home/dashboard** (and secondarily **Subscriptions**) read as "accidental — weird
borders, inconsistent spacing/padding" while the **Customers page looks good**. Root cause is
already measured and trusted: the good pages inherit the base `.ax-card` grammar consistently,
but Home's mid-page zones DRIFTED into ad-hoc per-zone values (3px/0px padding, `radius-sm` on
peer cards next to `radius-lg`, 1px/3px section gaps, accent-tinted borders + backgrounds on
several competing zones, and bordered boxes nested inside bordered boxes).

Define ONE **console-card grammar** and normalize Home's drifted zones to it, using Customers /
`.ax-card` as the visual reference. This is **Phase 2b** of the admin re-skin gameplan
(`~/.claude/plans/i-m-in-users-jon-projects-accrue-current-refactored-willow.md`).

**Strictly VISUAL / design-system consistency, CSS-only.** No IA restructure (redundant bands /
competing primaries belong to SEED-004, out of scope), no palette change, no copy/markup change.

### The console-card grammar (encode this, then apply it)

The admin is a **DENSE operator console** — do NOT balloon Home to the airy 24px Customers
spacing. The goal is CONSISTENT + INTENTIONAL, not spacious. Pick ONE console scale and apply
it to every peer zone on Home:

1. **One card radius on sibling zones** — use `--ax-radius-md` (10px) as the console-card
   default. Stop mixing `--ax-radius-sm` (8px) and `--ax-radius-lg` (14px) on peer cards.
2. **Space-scale padding only** — replace ad-hoc `0.1875rem` / `0.375rem` / `0` with tokens:
   card interior `--ax-space-md` (16px) for roomy cards, `--ax-space-sm` (8px) for compact
   strips. NO raw sub-`--ax-space-2xs` px padding on any card-level container.
3. **One vertical rhythm** — stacked Home sections share ONE gap token (use `--ax-space-md`,
   16px). No `0` / `0.0625rem` (1px) / `0.1875rem` (3px) gaps between peer zones.
4. **Plain borders, reserve accent** — sibling zones use `1px solid var(--ax-border)` (neutral
   card border). Reserve accent-tinted border/background (`--ax-accent-border` / `--ax-accent-subtle`)
   for exactly ONE genuinely-primary element. Stop the "every zone a different color" effect.
5. **De-nest borders** — a bordered container must NOT wrap bordered sub-cards. Group inner
   items with spacing + thin dividers, not boxes-in-boxes.

## Tasks

### Task 1 — Encode grammar + normalize Home dashboard zones (app.css) [PRIMARY]

Edit SOURCE `accrue_admin/assets/css/app.css` at the class level. Before editing, re-read
`.ax-card` and each Home zone class listed above to confirm current values (they may have
shifted). Apply the console-card grammar:

- **Vertical rhythm (principle 3):** set one shared gap token across peer sections. Recommended:
  `.ax-home` gap → `var(--ax-space-md)`; `.ax-home-section` gap → `var(--ax-space-md)` (or `-sm`
  for tightly-related sub-items, but pick ONE and use it consistently);
  `.ax-home .ax-home-section` `margin-block-start` → `0` (rhythm now comes from the parent gap,
  not per-section margins); `.ax-launchers` gap → `var(--ax-space-sm)` (compact grid) — no more
  1px / 3px gaps. Leave `.ax-home > .ax-page-header` header spacing intentional (it may stay
  tight), but replace any raw `0`/px gaps with a token if it reads cramped.
- **`.ax-home-customer-search-strip` (principles 1,2,4):** radius → `var(--ax-radius-md)`;
  padding → `var(--ax-space-sm)` (compact strip; drop the `0.1875rem 0.375rem`); gap → token
  (`var(--ax-space-2xs) var(--ax-space-sm)`). **Decide the accent question (principle 4):** make
  this a NORMAL neutral card (`border: 1px solid var(--ax-border)`, `background: var(--ax-elevated)`,
  drop the accent tint) UNLESS you deliberately keep it as the single accent zone — executor's
  call, but the whole page must end with AT MOST ONE accent-tinted zone. If you keep the accent
  here, then neutralize `.ax-launcher-primary`'s accent instead — never two competing accent
  boxes.
- **`.ax-launcher` (principles 1,2):** give the container real interior padding
  `var(--ax-space-sm)` (replace `padding: 0`); radius → `var(--ax-radius-md)` so launchers match
  the console-card radius. Keep the internal grid `gap` for label rows, but ensure content no
  longer butts against the border.
- **`.ax-launcher-primary` (principle 4):** this is a legitimate single primary — you MAY keep
  its accent treatment IF the search strip was neutralized above. Keep it visually deliberate
  (one accent element), not one-of-many.
- **`.ax-attention` + `.ax-attention-summary` (principle 5, de-nest):** remove the inner
  `border` (and its `radius-sm`) from `.ax-attention-summary` so the bordered `.ax-attention`
  wrapper does not contain bordered sub-boxes. Separate the summary from the rows with a thin
  bottom divider (`border-bottom: 1px solid var(--ax-border)`) + `var(--ax-space-sm)` padding
  instead of a full box. Preserve the warning variant's semantic hue as a divider/text accent,
  not as a full nested border-box.
- **"Jump to a task" / task-launcher + "search globally / dunning funnel" wrapper zones:**
  normalize any wrapper border/padding/radius the same way — neutral `1px solid var(--ax-border)`,
  `--ax-radius-md`, space-token padding. Sweep the `[data-ax-zone="attention-rail"]` /
  `[data-ax-zone="task-launcher"]` / `[data-ax-zone="kpi-cluster"]` `margin-block-start: 0`
  rule so the parent gap owns the rhythm.

Do NOT add a new token unless a shared grammar value is genuinely reused across files — if so,
theme.css is the only place a token may be added. Prefer using existing radius/space tokens.

Verify: `grep -nE "0\.1875rem|0\.0625rem|0\.03125rem|padding: 0;|radius-sm" accrue_admin/assets/css/app.css`
scoped to the Home zone blocks returns no remaining ad-hoc card-level values in the edited
selectors. Both light and dark themes remain legible.

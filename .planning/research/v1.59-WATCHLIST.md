# v1.59 Change Watchlist

**Operating rule:** Monitor before dependency/provider changes enter release. Each trigger creates a documented assessment, fixture update where applicable, and owner-phase/runbook execution; no alert may silently broaden entitlement access.

| Monitor | Trigger | Owner phase / runbook | Required response |
|---|---|---|---|
| Apple App Store Server API, ASSN V2, StoreKit, `appAccountToken` | Deprecation, new notification/status field, changed signing or linkage semantics | 217 Apple adapter runbook | Classify compatibility/security impact; update corpus; rerun independent verifier and sandbox conformance before release. |
| Apple PKI/x5c/OCSP | Root/intermediate rotation, OCSP outage/change, certificate advisory | 217 verification incident runbook | Validate pinned trust material and timeout policy; queue/retry transient failures; never grant from unverified material. |
| Apple transaction/status/history pagination | Cursor/revision contract change, sandbox retention change, stalled repair | 217/219 reconciliation runbook | Freeze cursor semantics, add interrupted/multipage fixture, repair affected lineages, alert on age/backlog. |
| Apple App Review/payment rules and regional external-purchase policy | New storefront, purchase CTA/link, rejection, entitlement/legal change | 219 App Review/legal checklist | Revalidate iOS purchase/restore/management UX; obtain legal/product approval; do not expose unsupported external purchase flow. |
| Stripe API/webhook version, retry/idempotency behavior | API-version bump, event schema change, delivery incident | 216/219 Stripe reducer runbook | Replay deterministic event corpus; preserve domain-object idempotency/outbox; reconcile ambiguous creates rather than retrying charge blindly. |
| `app_store_server_library` | Release, CVE, default-verifier/API change, failed corpus case | 217 dependency admission runbook | Keep adapter boundary; run corpus/API/supervision/privacy gates; pin or replace implementation if any gate fails. |
| `jose`, Erlang `:public_key`, Elixir/OTP crypto advisories | CVE, algorithm/default behavior change, OTP upgrade | 218 crypto/key incident runbook | Review algorithm allowlists and golden vectors; rotate key if exposure warrants; never permit fallback algorithm. |
| Crosswake verifier, secure storage, device-key APIs | Feasibility tracer failure, mobile SDK upgrade, secure-store incident | 218 Crosswake tracer / mobile security runbook | Prove thumbprint/high-water/atomic replacement contract; block reference proof if unmet; keep Accrue runtime decoupled. |
| Accrue host-owned Finch/Oban/key-provider integration | Host resource name/pool/queue/config change, worker backlog, key access outage | 215/219 operations runbook | Verify no Accrue-owned child was introduced; test retries/DLQ; preserve last known grant and suspend issuance on key failure. |
| Offline stale-access and abuse signals | Copied lease, clock anomaly, high stale rate, revocation complaint, deny loop | 218/219 security-product runbook | Investigate device/revision/key telemetry; force online/deny on next connection when warranted; do not add secret policy cutoffs. |
| Privacy, retention, deletion, support diagnostics | New jurisdiction, DSR, retention proposal, redaction scan failure | 219 privacy runbook | Confirm bounded evidence/access control/redaction; remove sensitive diagnostic exposure; update host data-ownership docs. |
| Google Play / SEED-007 | Android scheduled or a second concrete adopter requires it | Future milestone only | Create a separate rail-policy research milestone; do not add Play parity opportunistically. |
| Finance/support duplicate-purchase exceptions | Repeated incidents above agreed threshold | 219 support-finance runbook | Measure causes and document manual resolution; propose future transfer/migration policy only with explicit approval. |

## Review Cadence

- At dependency update, provider API-version change, and release candidate: execute the relevant row’s gates.
- Weekly while Apple repair is in rollout: inspect verification/quarantine/retry/backlog age and stale-lease/deny rates.
- Quarterly and after security incident: key rotation tabletop, dependency advisory review, and Crosswake contract retest.

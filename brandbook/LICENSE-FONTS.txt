FONT PROVENANCE FOR OUTLINED LETTERFORMS IN ACCRUE BRAND SVG FILES
====================================================================

The Accrue brand SVG files in brandbook/logo/ contain outlined letterform path
data derived from the Geist font family. These are fully outlined paths (not
embedded font data, not @font-face declarations, not live <text> elements) and
are committed as permanent visual brand artifacts.

This file documents the provenance and license terms for those outlined
letterforms.

--------------------------------------------------------------------
FONT NAME: Geist Sans Regular (weight 400)
USED IN:
  - brandbook/logo/accrue-logo.svg
  - brandbook/logo/accrue-logo-on-dark.svg
  - brandbook/logo/accrue-logo-mono.svg
  - brandbook/logo/accrue-logo-mono-inverse.svg
  - brandbook/logo/accrue-wordmark.svg
  - brandbook/logo/accrue-social-card.svg
  - brandbook/logo/favicon.svg
  - brandbook/logo/accrue-logo-subtitle.svg (wordmark portion)
  (and all raster derivatives in brandbook/logo/*.png and brandbook/logo/*.ico)

FONT NAME: Geist Mono Regular (weight 400)
USED IN:
  - brandbook/logo/accrue-logo-subtitle.svg (subtitle "Billing for Elixir apps")
  - brandbook/logo/accrue-social-card.svg (subtitle text)

FONT SOURCE: https://github.com/vercel/geist-font

--------------------------------------------------------------------
USAGE NOTE

Embedding font outlines as SVG path data in a graphic is an explicitly
permitted use under the SIL Open Font License 1.1. The OFL FAQ (question
1.12) confirms that converting letterforms to outlines for use in a logo or
graphic artwork is allowed. This usage does not constitute "bundling" or
"distribution" of the font software itself — only derived path geometry is
present in the committed files; the original font binaries are not included
in this repository.

The OFL's Reserved Font Name provision applies to font software distribution,
not to outlined artwork derived from the font. Accrue's outlined letterforms
are brand artifacts, not font software.

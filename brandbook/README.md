## Logo Usage

### Minimum sizes

| Variant | Minimum size | Notes |
|---|---|---|
| Icon-only mark (`accrue-mark.svg`) | **16px** | Favicon floor — the mark is legible at 16px; do not use below this size |
| Primary lockup (`accrue-logo.svg`) | **120px wide** | Below 120px the wordmark becomes illegible; switch to mark-only |
| With-subtitle lockup (`accrue-logo-subtitle.svg`) | **168px wide** | Below 168px, drop the subtitle and use the primary lockup instead |

### Clearspace

Clearspace equals one step-height of the mark on all four sides — for both the icon-only mark and the full lockup. See `accrue-clearspace.svg` for a visual diagram. The clearspace ratio is approximately 1:4 of the mark's height/width.

For the primary lockup, the step-height is ¼ of the mark's height. Apply this margin on all four sides of the outermost bounding box of the mark+wordmark group.

## Tagline Usage

The tagline "Billing state, modeled clearly." is editorial typography only — it is never included in a logo lockup file. For homepage headings, pair with Geist sans, Ink (#181818), at heading scale.

Do not create lockup variants that weld the tagline to the mark or wordmark.

## Font Provenance

All text in the brand SVGs is fully outlined — there are no live `<text>` elements or embedded `@font-face` declarations. Letterform paths are derived from:

- **Geist Sans Regular (400)**: wordmark "accrue" in `accrue-logo.svg`, `accrue-logo-on-dark.svg`, `accrue-wordmark.svg`, `accrue-logo-mono.svg`, `accrue-logo-mono-inverse.svg`, `accrue-social-card.svg`, `favicon.svg`, and their derived mark variants
- **Geist Mono Regular (400)**: subtitle "Billing for Elixir apps" in `accrue-logo-subtitle.svg` and `accrue-social-card.svg`

See `brandbook/LICENSE-FONTS.txt` for the full OFL 1.1 provenance statement.

## Regenerating

To regenerate all brand SVGs from the frozen R2-7 config:

```bash
# From the repo root:
node brandbook/logo/harness/generate-logo-suite.mjs
node brandbook/logo/harness/generate-rasters.mjs

# Determinism gate — must exit 0:
git diff --exit-code brandbook/logo/
```

If `git diff` reports any changes after a clean regeneration run, the pipeline has introduced non-determinism. Investigate before committing.

To run the size-matrix QA screenshot gallery:

```bash
node brandbook/logo/harness/size-matrix-qa.mjs
# Screenshots output to .planning/phases/183-logo-system-production/qa-screenshots/
```

The harness lives in `brandbook/logo/harness/` and requires Node.js with the packages in `harness/package.json` installed (`npm install` from that directory).
